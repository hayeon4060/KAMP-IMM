# 데이터 구분

- `original/`: 제공받은1차원본 labeled_data.csv/moldset_labeled.csv/unlabeled_data.csv.gz. 비라벨226MB는손실없는gzip22MB로보관,학습노트북이자동복원한다.
- `kamp/`: 대회제공2차표준화제품별라벨/비라벨4파일. 같은이름의원본제품분리CSV와바꿔넣으면안된다.
- `processed/cn7/`: 지우전처리Run/샷및비라벨연결결과.
- `processed/rg3/`: 가스학습583샷,미성형학습574샷,예측스키마591샷.
- `runtime/`: 압축복원/호환실행임시CSV(대용량Git제외).

원본과가공데이터는사용자요청으로이배포에포함한다. 재배포/대회사용권한은원제공기관약관을따라야한다. 원본데이터공개권한을별도로보증하지않는다. 데이터량/센서값을보고불량으로임의라벨링하지않는다.
