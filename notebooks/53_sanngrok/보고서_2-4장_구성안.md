## 0. 한 줄 스토리

> **"불량 유형마다 흔적이 남는 방식이 다르다 → 하나의 모델로는 안 되고, 유형별 탐지기를 하나의 검사 순위로 묶어야 한다."**

53개 노트북을 다 보여주지 말고, 이 한 줄을 증명하는 **모델 5개(B0~B3, P)**만 본문에 쓴다. 나머지는 부록 표 한 장으로 정리.

## 1. 2장 흐름 — "일반적인 방법 → 왜 실패 → 무엇을 바꿨나" 4단계

### 2-1·2-2. 평가 조건을 먼저 고정 (모든 모델 공통)

| 항목 | 설정 | 이유 |
|---|---|---|
| 평가 단위 | 샷 (LH/RH 공정값이 같음) + 보조로 공식 2차 행 | 같은 입력 → 같은 판정 |
| 평가 틀 | ① 공식 2차 / ② labeled 전체 (초기허용 제외, RG3 R6 제외) | 2차만 쓰면 불량 수가 너무 적음 |
| 분할 | Run 하나씩 빼기(LORO) + 시간 순 학습(과거 Run만) | 불량이 Run 안에 몰려 있음 → 랜덤 분할하면 옆 샷이 정답을 알려줌 |
| 지표 | 검사 5·10·15%에서 잡은 불량 수, 무작위 대비 배수, Precision/Recall/F1, AP | 현장 질문 = "몇 % 검사해서 몇 개 잡나" |
| 반복 | 시드 3개 평균, 무작위는 20번 평균 | |

- 랜덤 분할을 쓰면 안 되는 근거 한 줄: 같은 RF가 랜덤 CV에서는 PR-AUC 0.448, 시간 분할에서는 0.004 (타 팀 공개 결과, 53번)

### 2-3·2-4. 비교 모델 5개 — 순서 자체가 이야기

| 단계 | 모델 | 질문 | CN7 검사 10% (2차 / 전체) | RG3 검사 10% |
|---|---|---|---|---|
| ① 기준 | **B0 무작위 검사** | 아무것도 안 하면? | 1.6/14 · 1.7/15 | 2.4/25 |
| ② 일반적 접근 | **B2 단일 RF (불량 전체 학습)** | 라벨로 바로 학습하면? | **0/14 · 0/15** | 6.0/25 (2.5배) |
| ③ | B3 단일 RF + 정상 데이터 보강 | 정상 샘플을 늘리면? | 0/14 · 1.0/15 | 5.0/25 |
| ④ 라벨 없이 | **B1 정상 기준 이상탐지 (Mahalanobis)** | 정상만 배우면? | **5/14 · 5/15 (3배)** | 2.0/25 (무작위 이하) |
| ⑤ 제안 | **P 통합 모델 (유형별 탐지기 → 순위 1개)** | 유형별로 나누면? | **6/14 · 8/15 (4.7배)** | **10.0/25 (4.2배)** |

**단계별로 쓸 해석 (숫자만 나열하면 감점이니 '왜'를 꼭 붙이기)**
- ② → CN7은 불량이 Run 1개(R1)에만 있어서, 다른 Run으로 일반화할 패턴이 없음. 지도학습의 한계
- ④ → 급변형 불량(CN7 미성형)은 "정상에서 얼마나 벗어났나"만으로 라벨 없이 잡힘. 하지만 RG3처럼 흔적이 약한 불량은 못 잡음
- ②와 ④의 결과가 제품마다 반대 → **불량 유형별로 다른 탐지기가 필요**하다는 근거
- ⑤ → CN7 = 비지도 경보(미성형)를 맨 위 + 흔들림(std4) 순위로 나머지 채움 (라벨 0개) / RG3 = 가스 RF(흔들림 변수) + 미성형 모델을 68:32로 번갈아 합침

### 2-5. 그림·표
- 검사 비율(5·10·15%) × 모델 곡선 1장 (`unified_model/curves.csv`)
- 위 비교표 + 무작위 대비 배수
- 신뢰성 표: RG3 가스 RF 순열검정 p = 0.007, 시드 5개 모두 8/17 / CN7 미성형 경보 Holm p = 0.048

### 2-6. 최종 모델 선정 근거 (4개 기준)

| 기준 | P 통합 모델 |
|---|---|
| 성능 | 검사 10%로 무작위 대비 CN7 4.7배, RG3 4.2배. 모든 비교 모델보다 높음 |
| 안정성 | RG3 가스 부분: 순열 p 0.007, 시드 안정. CN7 미성형 부분: 라벨 없이 정한 임계값 |
| 해석성 | 검사 샷마다 "어느 탐지기가 올렸는지"(= 추정 원인)가 같이 나옴 |
| 현장성 | CN7은 라벨 0개. RG3는 시간 순(과거 Run만) 학습으로도 10/25 → 실제 운영 조건과 같음 |

**솔직하게 쓸 한계**: CN7의 흔들림(std4) 부분은 가스가 R1 한 Run에만 있어 통계적으로 검증되지 않음 (순열 p 0.15~0.25) → "가설 단계"로 표기

### 부록 — 시도했지만 채택하지 않은 방법 (한 표로)

| 방법 | 결과 | 안 쓴 이유 |
|---|---|---|
| 샘플링 19종 (SMOTE 등) | 가중치보다 나은 경우 없음 | 정상 흔들림 폭을 덜 배움 |
| 관계 잔차 (타 팀 방식) | 최종 모델과 같은 샷만 잡음 | 추가 정보 없음 |
| 시퀀스 오토인코더, GBM+SHAP, 준지도, 변화점 등 | 최종 이하 또는 우연 수준 | 37번 탐색 보정 검정 |
| 사람이 고른 온도 규칙 | 같은 절차를 코드로 돌리면 2/11 | 선택 편향 (p 0.11) |

→ 이 표가 있으면 "53개 노트북"이 산만함이 아니라 **철저함**으로 읽힘

## 2. 3장 — 영향요인 및 오류분석

### 3-1. 주요 영향변수 (공정 의미로 해석)

| 불량 | 모델이 반응한 변수 (경보 샷의 상위 기여) | 공정 해석 |
|---|---|---|
| CN7 미성형 (R1 59~61번째 3샷) | 사출속도 편차 **+20σ**, 흐름저항(압력/속도) **−20σ**, 충전시간 편차 −8.8 | 같은 압력에서 속도가 급등 = 수지가 너무 쉽게 흐름(점도↓·재료 부족) → 충전 단계 이상 |
| RG3 가스 | 직전 10샷 **흔들림(std)**: 쿠션위치·배럴·호퍼 + 배압·스크류 회전 | 한 샷의 튀는 값이 아니라 공정이 불안정한 구간 |
| CN7 가스 | 샷 단위로 튀는 변수 없음. R1만 금형온도 25.0℃ (다른 Run 21.4~22.8℃) | Run 전체 특성 → 샷 예측이 아니라 Run 관리 대상 |

### 3-2. 잘 작동하는 조건
- **급변형 불량**: 공정값이 한 샷에서 크게 튀는 경우 (CN7 미성형 3/4, 상위 0.2% 안)
- **불안정 구간형 불량**: 여러 샷에 걸쳐 흔들리는 경우 (RG3 가스 8/17, 우연 대비 p 0.007)
- 재가동 직후 이상: 초기허용 5샷 모두 상위 0.5% (평가에서는 제외했지만 모델은 잡음)

### 3-3. 미탐지(FN) 분석 — 놓친 이유를 "데이터에 정보가 없다 / 모델 한계"로 구분

| 놓친 불량 | 공통점 | 원인 구분 |
|---|---|---|
| CN7 가스 11샷 | 모두 R1 25~58번째. 최대 편차가 호퍼온도 +5σ 정도로 약함 | **Run 특성형** — 샷 단위 신호가 약함. 불량 Run이 1개라 검증 불가 |
| CN7 R6 미성형 1샷 | LH만 불량, 모든 변수 편차 ≤ 0.7σ | **데이터에 정보 없음** — 공정값이 정상과 같음 |
| RG3 불량 25샷 | **25/25 전부 RH 캐비티**, 같은 시각 LH는 양품 | **데이터에 정보 없음** — LH/RH가 같은 공정값을 공유 → 캐비티 차이는 관측 불가 |
| RG3 미성형 | 어떤 변수 탐색도 우연 수준 (무작위 라벨로도 평균 3.5/8) | 데이터 한계 |

### 3-4. 오경보(FP) 분석 — "과도구간"에 몰림

| 사례 | 내용 |
|---|---|
| CN7 q0.999 경보 8샷 | TP 3 (R1 미성형) + FP 5 → **FP 5개 전부 과도구간**: 재가동 1·2·3번째 샷 3개, Run 마지막 2샷 2개 |
| CN7 q0.99 FP 26샷 | 11개(42%)가 재가동 후 5샷 이내 — 그런 샷은 전체 정상의 2.8%뿐 → **15배 집중** |
| RG3 q0.999 FP 3샷 | 전부 R2 시작 3~5번째 샷 (호퍼온도 기울기) |

→ 오경보는 "모델이 틀린 것"이라기보다 **공정이 실제로 안정되지 않은 구간**을 잡은 것. 운영 규칙으로 분리 가능 (4장)

### 3-5. 정리 → 4장 연결

| 발견 | 4장 조치 |
|---|---|
| 급변형은 라벨 없이 잡힘 | 즉시 경보 (q0.999) |
| 흔들림형은 순위로 잡힘 | 검사 예산 10% 순위 |
| 오경보는 과도구간에 몰림 | 재가동 직후·Run 끝 샷은 "과도구간 경보"로 따로 표시 |
| RG3 불량은 전부 RH | RH 우선 검사 + 캐비티별 센서 제안 |
| CN7 가스는 Run 특성 | Run 시작 시 금형온도 점검 |

## 3. 4장 — 현장 활용방안

### 4-1. 운영 흐름

```
샷 생산 → 점수 계산(직전 20샷 기준선) → ┬ ① 즉시 경보 (pct ≥ 0.999) → 해당 샷 LH/RH 격리 + 원인 변수 표시
                                         ├ ② 과도구간 표시 (재가동 ≤3샷, Run 끝) → 초품 검사 규칙으로 처리
                                         └ ③ 검사 순위 (상위 10%) → 샘플 검사 → 불량 발견 시 피드백
```

### 4-2. 검사 우선순위 규칙

| 규칙 | 대상 | 근거 (수치) |
|---|---|---|
| R1 즉시 경보 | 두 제품, pct ≥ 0.999 | CN7 경보 8샷 중 미성형 3 (정밀도 37.5%, 2차 기준 60%), 무작위 대비 26~49배 |
| R2 순위 검사 | 검사 예산 10% | CN7 8/15 (4.7배), RG3 10/25 (4.2배) |
| R3 주변 확장 | CN7: 불량 발견 시 앞뒤 **3샷 연쇄 추가 검사**(예산 밖) | CN7 5 → 12/14, 추가 13샷(총 검사 10.1% → 12.2%). 예산 안 확장은 ±3~20 모두 8/14 (53-C). RG3는 9 → 7로 떨어져 적용 안 함 |
| R4 캐비티 우선 | RG3: RH 먼저 검사 | 불량 25/25가 RH → 검사량 절반으로 불량 전체 커버 |
| R5 과도구간 | 재가동 3샷 이내·Run 마지막 샷 경보 | 오경보의 대부분 → "과도구간" 태그로 분리 |

### 4-3. 검사 예산별 효과 표
- 5·10·15% 검사에서 잡은 불량 수, 무작위 대비 배수 (`unified_model/rows.csv`, `curves.csv`)
- 예: RG3 5% 검사 7.3/25 = 무작위 9.2배

### 4-4. 작업자 의사결정 지원 — 경보 카드

| 표시 항목 | 예시 (CN7 R1 05:55 미성형) |
|---|---|
| 탐지기 (추정 원인) | 최종 모델 경보 → 급변형 |
| 이상 변수 Top 3 | 사출속도 +20σ, 흐름저항 −20σ, 충전시간 편차 |
| 점검 권고 | 재료 공급·계량 상태, 수지 건조 상태 확인 |

RG3 가스 RF 경보면 "직전 10샷 흔들림: 쿠션위치·배압" → 계량 안정성 점검

### 4-5. 기대효과
- 같은 검사량으로 불량 포착 4~5배 (무작위 샘플 검사 대비)
- **unlabeled 실데이터 검증**: RG3 통합 경보율과 날짜별 실제 불량률(ERR_FACT_QTY)의 상관 **ρ = 0.88** (18일, labeled 날짜 제외, p < 0.001) → 일 단위 품질 모니터링 지표로 바로 활용 가능. CN7은 상관 없음 (ρ ≈ 0) → 한계로 기술
- 비용 정량화: 불량 유출 1건 비용 C₁, 검사 1샷 비용 C₂ 가정 → (추가 포착 불량 × C₁) − (검사 샷 × C₂)

### 4-6. 도입 시 고려사항
- 정상 기준 재학습: 금형 교체·설정 변경 시, 또는 월 1회 (라벨 불필요)
- 임계값: 정상 오경보율로 정함(q) → 라벨 없이 갱신 가능
- RG3 가스 RF: 새 불량 라벨이 쌓이면 시간 순으로 재학습
- **추가 센서 제안**: 캐비티별(LH/RH) 압력·온도 센서 — 현재 데이터로는 RG3 RH 불량을 관측할 수 없기 때문 (3-3 근거)
