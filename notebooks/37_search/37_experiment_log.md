## 반복 1 — 누적 점수(EWMA) : "가스는 한 구간에 몰려 있으니, 약한 이상이 쌓이는 걸 보자"

- **이전 관찰**: CN7 가스 11건은 모두 R1의 25~58번째 샷에 몰려 있고, 최종 모델은 샷 하나하나의 순간 편차만 봄 → 가스 샷 각각은 약하게만 튐
- **바꾼 것**: 최종 모델 pct를 Run 안에서 지수이동평균(span 5·10·20)으로 누적 → 단독 / max(최종, 누적)
- **결과**: 모두 실패. CN7 누적 단독은 가스 0/11, max(최종, 누적)은 가스 2/11로 최종과 같고 ② AP는 0.161로 하락. RG3도 변화 없음
- **해석**: 가스 구간의 최종 모델 점수가 '약하게 계속 높은' 형태가 아님. 누적하면 미성형의 날카로운 피크만 흐려짐

## 반복 2 — 흔들림 전문가(std4) : "하연님이 RG3 가스에서 찾은 흔들림 신호를 CN7에도 (독립 가설로) 적용"

- **이전 관찰**: RG3 가스는 쿠션위치 직전 10샷 std가 147개 변수 보정 뒤에도 유의 (34번). CN7에는 아직 안 써 봄 → CN7 입장에서 '라벨을 안 보고 정한' 가설
- **바꾼 것**: std4(배럴2·호퍼·쿠션·배럴5 직전 k샷 std, k=5·10·20) Mahalanobis, 정상 reference 학습 → 단독 / max(최종 pct, std4 pct)
- **결과**: CN7 std4_k10 단독 가스 5/11(미성형 0/4), 합치면 가스 1~2/11로 다시 떨어짐. RG3 std4_k5 단독 가스 2/17·미성형 3/8 (② AP 0.066)
- **해석**: std4 점수는 정상 샷에서도 높은 값이 흔함 → 정상 reference 백분위로 합치면 std4 쪽 상위가 정상 샷으로 채워져 가스가 못 올라옴

## 반복 3 — 온도 제어 흔들림 + 순위 교차(interleave) : "합치는 방식을 바꾸고, 온도 흔들림 전체를 보자"

- **이전 관찰**: CN7 단변수 스캔에서 '배럴2 온도 직전 10샷 std'가 가스를 상위 10%에 9/11 올림 → 온도 제어 불안정이 가스와 관련 있을 가능성.
  다만 라벨을 보고 고른 변수 → 그 변수 하나를 쓰는 대신, 사전에 정할 수 있는 묶음(온도 9개 / 배럴 6개 / std4)으로 확장
- **바꾼 것**: ① 묶음별 std Mahalanobis ② 합치기를 'labeled 안 순위의 max'(검사 예산을 두 전문가가 반씩 나눠 쓰는 것과 같음)로 변경
- **결과**:

| CN7 | ② AP | 상위10% 가스 | 상위10% 미성형 | ① AP |
|---|---|---|---|---|
| final | 0.212 | 2/11 | 3/4 | 0.373 |
| 온도 9개 std (k5) 단독 | 0.017 | 4/11 | 0/4 | 0.028 |
| interleave(final, std4_k5) | 0.123 | 2/11 | 3/4 | 0.392 |
| E_thermal (R1에서 도출, 사후) 단독 | 0.259 | 6/11 | 3/4 | 0.417 |
| **interleave(final, E_thermal)** | **0.286** | **6/11** | **3/4** | **0.449** |

- **해석**: 사전 가설(흔들림 묶음)은 묶으면 신호가 희석됨. 목표를 넘은 건 R1에서 방향을 정한 온도 교란 점수 E와 합친 경우뿐 → **반드시 선택 편향 검증 필요** (반복 6)

## 반복 4 — RG3 지도학습 (Run 하나씩 빼고 검증, LORO) : "RG3는 불량이 4개 Run에 퍼져 있어 지도학습을 정직하게 검증할 수 있음"

- **결과**: 최고 `lgbm|std_only` ② AP 0.092, 가스 5/17, **미성형 0/8**. 미성형을 잡는 설정은 없음 (최대 1/8)
- **해석**: 흔들림(std) 변수가 RG3 가스를 가장 잘 설명 (34번·하연님과 일치). 미성형은 다른 Run으로 일반화되는 신호가 없음

## 반복 6 — 검증: 목표를 넘은 'interleave(최종, E)'는 믿을 수 있나

- **이전 관찰**: 반복 3에서 CN7 목표(가스 6/11, 미성형 3/4, ② AP 0.286 > 0.212)를 처음 넘었지만, E는 R1 가스를 보고 성분·부호를 정한 규칙
- **검증 방법 1 — 절차 재실행**: 26~29번에서 사람이 한 절차(가스 vs 시간 맞춘 정상 δ로 온도 성분 고르기 → 부호 맞춘 합 → 최근 5샷 평균)를 코드로 고정하고 그대로 다시 실행
  - 기계적으로 고르면 `호퍼 기울기·호퍼 편차·호퍼 상승`이 뽑히고(금형 편차는 4위), 이걸로 합치면 **가스 2/11** (목표 미달)
  - 즉 목표 달성은 '금형 편차를 넣고 호퍼 상승을 뺀' 사람의 선택에 달려 있었음
- **검증 방법 2 — 부분집합 전체 + 탐색 보정 순열검정**: 6개 온도 성분의 2~3개 조합 35개 중 목표 달성은 3개(모두 금형 편차 포함).
  라벨을 Run 안에서 원형 이동(불량이 몰린 구조는 유지, 위치만 무작위)해 같은 35개 탐색을 200번 반복 → 무작위 라벨에서도 최고값 평균 1.67, 95% 지점 9
  → **탐색 보정 p = 0.109 (유의하지 않음)**
- **결론**: interleave(최종, E)의 CN7 목표 달성은 **신뢰할 수 없음** (R1 하나에서 성분을 골라 R1을 맞힌 결과). 보고서에는 '가설·파일럿'으로만

## 반복 7 — 변수 은행 전체 탐색 + 탐색 보정 : "사람이 고르지 말고, 212개 후보 전부를 같은 기준으로 보고 우연 수준과 비교"

## 최종 정리 (반복 19회, 21:33~22:5x)

### 2시간 전에 멈춘 이유

- 남은 방향은 모두 "라벨을 보고 변수·조합을 고르는 탐색"인데, 반복 6·7·14·17에서 이런 탐색은 CN7 가스와 RG3 미성형에서 **무작위 라벨로도 같은 수준이 나온다**(우연 수준)는 걸 확인함
- 시간을 더 써서 목표 숫자를 맞추는 설정을 찾더라도 검증을 통과할 수 없어서, 신뢰할 수 있는 결과(RG3 가스)를 굳히고 정리함

### 목표 달성 여부

| 제품 | 목표 | 신뢰할 수 있는 최고 결과 | 달성 |
|---|---|---|---|
| CN7 | 미성형 3~4 유지 + 가스 ≥ 6/11 | **최종 모델 유지** (미성형 3/4, 가스 2/11, ② AP 0.212). 가스 6/11 이상은 ① R1에서 고른 온도 규칙(탐색 보정 p 0.11, 기계적 재실행 시 2/11) ② R1 전체를 올리는 수준 변수(무작위 라벨에서도 76% 달성)로만 나옴 → 탐지력의 증거가 아님 | **미달** |

### 채택 제안

1. **CN7 = 최종 모델(M_maha_free) 그대로.** 19번 반복 중 CN7을 신뢰할 수 있게 넘은 방법 없음
2. **RG3 = 가스 전용 RF(std10, 새 변수 포함)를 RG3 모델로 추가** — LORO·시드·부트스트랩·재학습 순열검정을 모두 통과한 유일한 개선
   - 보고서 표기: "② AP 0.048 → 0.12 (LORO), 가스 상위 10% 1/17 → 8/17, 재학습 순열검정 p < 0.01, ΔAP 95% CI 하한 ≈ 0 (경계)"
   - 한계: std 창 길이 민감(5샷 3/17, 20샷 4/17) — 10샷은 하연님 사전 설정. 지도학습이라 R1~R5(불량 25샷)에서만 검증됨
3. **RG3 미성형** → 모델 대신 운영 규칙: R6 제외 기준 RG3 불량 25샷(가스 17·미성형 8)은 **전부 RH 캐비티** → RH만 우선 검사하면 검사량 50%로 불량 전체를 덮음, 3장에 '관측 불가' 근거로 반복 14·17 사용. 배압 급상승은 '계량 불안정' 가설 단서로만

### 실패에서 배운 것 (보고서 3장·5장 재료)

1. **전체 상위 k% 지표는 Run 식별로 속일 수 있음** — CN7은 불량 Run(R1, 188샷)이 검사 예산(198샷)보다 작아, R1을 통째로 올리는 변수(금형온도 수준)가 무작위 라벨에서도 76% 목표 달성. Run별 지표 + 원형 이동 순열검정을 같이 봐야 함
2. **사람이 성분을 고르면 결과가 만들어짐** — 온도 교란 규칙 E는 같은 절차를 코드로 다시 돌리면 가스 2/11. 35개 조합 중 3개만 목표 달성
3. **이산 변수는 동점 처리가 결과를 바꿈** — 배압(0.1 단위) 상승의 미성형 4/8 중 2개가 동점 순서의 우연
4. **관계 이탈(B)은 보정을 고쳐도 추가 정보가 없음** — 경보율 58% → 0.8%로 고쳤지만 성능은 최종 미만
5. **RG3 가스는 '흔들림'이 진짜 신호, 제품 간 이전은 안 됨** — 단변수는 우연 수준이지만 흔들림 묶음을 RF로 합치면 우연을 넘음. RG3→CN7, CN7→RG3 이전은 실패 → CN7·RG3를 따로 보는 팀 결정이 맞음

  - 언더+업: 무작위 3:1·10:1 + 복제·SMOTE·ADASYN / 결합: SMOTE+ENN, SMOTE+Tomek / 앙상블: BalancedRandomForest, EasyEnsemble
  - ⚠ 샘플링은 각 학습 fold 안에서만 (평가 Run에는 적용 안 함)
- **결과 요약** (상위 10%, 시드 3개 평균)

| 타깃 | 방식 | ② AP | 가스 | 미성형 |
|---|---|---|---|---|
| 가스 | 가중치만 (기준) | 0.104 | **6.7** (5~8) | 1.7 |

| 미성형 | 업 무작위 복제 | 0.084 | 4.3 | 3.0 |

- **해석**
  - 가스: 샘플링이 가중치보다 나은 경우 없음 (EasyEnsemble만 AP가 비슷하거나 조금 높음). 정상을 버리면 '정상 흔들림의 폭'을 덜 배워서 오히려 떨어짐
  - 미성형: 언더+업 조합이 평균 3.3/8까지 올림(가중치 1.3) → 개선 방향은 맞지만, 미성형 AP는 0.045~0.048로 여전히 낮고,
    19가지 중 최고를 고른 값이라 반복 14의 '우연 수준(평균 3.5, 95% 4)' 안에 있음 → 목표 4/8을 안정적으로 넘는 방식은 없음
