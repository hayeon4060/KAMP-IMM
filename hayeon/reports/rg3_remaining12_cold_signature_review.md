# 개선 후보가 놓친 RG3 가스12개: 공통점과 추가 보완 모델

## 먼저 결론

현재 탐색 후보는 전체가스17개 중5개 탐지·정상오탐6개(F1=0.357)다. 기존4개·오탐6개보다 수치상 균형이 좋아졌다. 그러나 추가1개를 보고 만든 가설이고 내부 조건 선택이 동률에 의존한 탐색 결과다. 독립적인 일반화 성공이나 실제 대회 성적 개선은 아니다.

업데이트된 요청에 따라 남은12개를 다시 분석하고 다른 특징을 학습하는 보완 모델을 만들었다. 추가 탐지 가능성은 있지만 오탐 때문에 현재 후보에 더 붙이지 않았다.

- 정상566개 중150개(26.5%)도 이 패턴이었다. 누락가스5/12(41.7%)와 차이는 있으나 표본이 작고 정상에도 흔해서 단일 분류 규칙으로 쓰기 어렵다.

- 나머지 사례들은 배럴5가 상승하거나 거의 변하지 않는 등 방향이 달랐다. 12개 모두를 설명하는 공통 센서 변화는 이번에 확인되지 않았다.

왜 안 잡혔는지의 모델 설명은 기존 전문가 점수가 각 구간 경계보다 낮았고, 새 후보는 현재 온도 상승 확인 분기이므로 하락·안정 패턴을 추가로 잡는 구조가 아니라는 것이다. 실제 가스 발생 원인을 밝힌 것은 아니다. 센서에 구분 정보가 원천적으로 없다고도 단정하지 않는다.

## 새 피처6개와 보완 앙상블

1. 배럴5 현재−직전 변화
2. 사출압력 현재−직전 변화
3. 호퍼 현재−직전 변화
4. 쿠션 현재−직전 변화
5. 배럴2 변화−배럴5 변화 (온도 변화 방향 차이)
6. 배럴5 변화×압력 변화 (같이 변하는 정도)

현재 샷 측정과 이전 측정만 쓴다. 예측 이후 샷은 포함하지 않는다. 공정 변수 단위의 물리적 에너지·가스량으로 해석하지 않는다.

학습 구간에서 냉각·비상승 패턴인 가스와 모든 정상을 학습한다. 다른 패턴의 가스를 정상으로 잘못 라벨링하지 않고 학습에서 제외한다. 실제 가스/미성형 라벨을 새로 바꾼 것이 아니라 보완 탐지기의 학습 대상만 나눈 것이다.

RF100/depth5/leaf3/balanced_subsample와 LogisticRegression C=0.1/1/10의 평균을 사용했다. RF·로지스틱 평균, 두 점수 평균·기하평균도 비교했다. 결측 대체·정규화와 점수 임계값은 학습 내부 구간 제외 정상만 사용한다. 모델 사이 feature scaling은 내부 학습 정상으로 fit한다.

새 분기는 현재 후보의 탐지를 지우지 않고 OR로 추가한다. 내부 증거가 없는 분기를 억제하는 보수적 선택은 기존 RF 내부점수 대비 추가TP≥1·추가FP≤2·F1 상승이 있을 때만 허용한다. 전역 후보의 OOF 점수를 내부 학습에 재사용하면 바깥 구간 정답이 들어갈 수 있으므로 사용하지 않았다. 이 선택 검사는 원래 RF 기준의 내부 추가 유효성 검사로, 전체 3-seed 앵커의 완전 중첩 검증과 같다고 주장하지 않는다.

임계값은 내부 정상 상위0.5% 기준이다. 외부 정상 오탐률을0.5%로 보장한다는 의미가 아니다.

- 전체에서 로지스틱 보완 모델이 **2020-10-22 01:04:15**를 새로 잡아6개가 됐다. 하지만 오탐이6→12라 F1=0.343으로 기존5/6 후보의0.357보다 낮다.
- 과거 평가에서 냉각 RF가 **2020-10-22 07:37:31**를 추가해4/6/F1=0.348이었다. 하지만 전체 평가에서는 같은 모델로 추가 가스를 잡지 못해5/8/F1=0.333이다. 학습 구간 구성에 따라 탐지가 달라졌다.
- 내부 증거를 요구하는 보수적 보완 분기는 전체5/6, 과거3/4를 유지했다. 보완 모델을 안 붙이는 쪽으로 돌아간 결과다.

## 판단

이번 탐색 목표(TP≥5·FP≤6)를 만족한 후보는47번 세 seed 평균 + 현재 배럴5 상승 확인 분기다. 냉각 보완 모델을 추가한 후보가 아니다. 보완 실험으로 또 다른 누락 샷에 신호가 있음을 확인했지만 현재는 오탐 증가 때문에 채택하지 않는다.

남은 누락은 서로 다른 하락·안정·이력 부족 상태여서 하나의 규칙을 덧붙인다고 함께 해결되지 않았다. 다음 실제 성능 주장에는 새 생산 구간 또는 앞으로 확보하는 라벨로 선택 규칙을 고정한 검증이 필요하다. 지금 보유 데이터에서 반복 탐색한 최고값을 독립 성능으로 포장하지 않는다.
