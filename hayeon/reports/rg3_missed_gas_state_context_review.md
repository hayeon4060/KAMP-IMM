## 핵심 결론

기존 RF가 놓친 13개는 판정선 바로 아래에 몰려 있지 않았다. 점수는 0.014~0.309였고 각 구간 판정선은 0.442~0.579였다. 점수와 판정선 차이가 0.05 미만인 누락 가스는 0개다. 단순히 판정선을 조금 낮추는 방법으로 해결될 상황은 아니다.

놓친 13개 중 8개는 같은 구간 정상 점수의 75백분위 이하였다(그중 1개는 이력 결측). 이 수치는 **기존 모델이 기존 입력으로 가스 신호를 강하게 인식하지 않았음**을 뜻한다. 전체 센서에서 차이가 없거나 가스가 실제로 발생하지 않았다는 뜻은 아니다.

가스가 발생한 물리적 원인은 이 데이터·모델 점수만으로 확정할 수 없다. 건조, 수분, 배기 등 직접 측정되지 않은 원인이 있다고 단정하지 않는다.

## 만든 파생피처 6개

온도·압력 상태가 다르면 같은 흔들림 값도 의미가 다를 수 있다는 가설이다. **비슷한 공정 상태의 정상과 비교했을 때** 흔들림이 얼마나 다른지 계산한다.

상태 기준: 사출압력, 평균배압, 배럴2, 배럴5, 호퍼의 과거10샷 중앙값. 기존 dev10은 현재−과거중앙값이므로 현재−dev10으로 복원했다. 평균값이 아니다. 이 중앙값이 없으면 현재값으로 상태를 대체한다.

| 피처 | 쉽게 설명 |
|---|---|
| 상태 대비 배럴2 흔들림 편차 | 비슷한 공정 상태의 정상20개보다 배럴2가 더/덜 흔들리는지 |
| 상태 대비 호퍼 흔들림 편차 | 동일 방식의 호퍼 차이 |
| 상태 대비 쿠션 흔들림 편차 | 동일 방식의 쿠션 차이 |
| 상태 대비 배럴5 흔들림 편차 | 동일 방식의 배럴5 차이 |
| 정상 흔들림 지지 거리 | 흔들림4개 조합이 학습 정상의 가까운5개와 얼마나 다른지 |
| 상태 참조 거리 | 비교할 수 있는 비슷한 상태의 학습 정상이 얼마나 가까운지 |

비교 정상은 바깥 학습 구간 안에서만 선택한다. 학습용 피처도 내부 구간 제외 방식으로 만든다. 결측 대체·정규화 역시 해당 학습 정상으로만 학습했다. 흔들림 입력이 비면 6개 피처도 결측으로 두며, 부족한 이력에서 만들어진 인위적인 편차를 새 신호로 사용하지 않았다.

모델은 RF+ExtraTrees 각100개 트리/깊이5/최소잎3/balanced/seed42, 평균·최댓값 앙상블이다. 임계값은 내부 구간 제외 예측의 정상99% 경계다. 외부 정답으로 맞추지 않았다.
