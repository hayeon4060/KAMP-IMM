# RG3 가스 F1 0.5 목표 — 개발 진행 기록

## 평가 기준 고정

- RG3 RH 정상601개 + 가스19개 =620개. original에서 확인한 추가37개를 포함한다.
- CN7는 이번 실험93~96에 사용하지 않았다. 다른 불량8개는 정상으로 섞지 않고 제외했다.
- 같은7개 라벨 관측구간을 외부 평가에서 차례로 제외한다. 구간은 실제 연속운전 Run 확정값이 아니다.
- 각 외부 평가를 제외한 나머지 구간 안에서 다시 OOF 예측을 생성하고, 앙상블 가중치 및 임계값을 선택한다.
- 현재 사용자가 지정한 F1 목표를 우선한다. 동률이면 탐지율, 다음으로 오탐이 적은 것을 선택한다. 이전의 탐지율 우선 선택과 다르다.
- 이미 여러 번 본 자료의 중첩 구간검증이다. 새 독립 검증이라고 주장하지 않는다. 평가 정답으로 임계값을 고르거나 F1 0.5를 보장하지 않는다.

## 완료한 실험: 전체 선택 절차의 성적

좋은 후보 행만 골라 최고 기록이라고 부르지 않고, 학습 내부에서 후보와 임계값을 선택한 **전체 절차**를 주결과로 사용한다.

| 실험 | 찾은 가스 TP | 정상 오탐 FP | 놓친 가스 FN | 맞힌 정상 TN | F1 |
|---|---:|---:|---:|---:|---:|
| 93: RF/ET 전문가3개 가중치·임계값 공동 선택 | 6 | 48 | 13 | 553 | **0.164** |
| 94: CatBoost/LGBM/XGB 평균 전문가 추가 | 3 | 19 | 16 | 582 | 0.146 |
| 95: 정상 기준 점수 단위·앙상블·임계값 선택 | 3 | 30 | 16 | 571 | 0.115 |
| 96: 배럴 온도 프로파일 모양 전문가 추가 | 3 | 19 | 16 | 582 | 0.146 |

**93~96 묶음의 주결과 최고는 F1 0.164. 후속97~101의 주결과 최고는 F1 0.169이며 목표0.5는 미달성이다.** 이전 순위75 고정 후보의8개 탐지·61개 오탐(F1 0.182)은 개발용 좋은 후보 행이지 위 전체 선택 절차 성적과 같지 않다.

예전17개 평가의4개 탐지·6개 오탐 모델 결과와 현재620개 평가를 직접 비교하지 않는다. 93번은 예전 RF의 설정(200/depth8/leaf3/balanced_subsample/seed42)을 맞춘 단독 비교도 현재 동일 자료/구간에서 다시 계산했으며, 그 값은 F1 임계값 선택 시 TP6/FP53/FN13/TN548(F1 0.154)이었다. 예전 학습 모델의 고정 예측을 그대로 재사용한 것은 아니다. 주후보는 여러 모델 평균 앙상블이다.

## 어떤 변수와 모델을 썼나?

- std4: 배럴2/Hopper/쿠션/배럴5의 과거10샷 표준편차.
- 상태10: Hopper·배럴2/5·쿠션·계량시간·사출압력-전환압력 차이6개 +std4.
- 조건부 순위75: 위10개 특징을 다른9개가 비슷한 학습 정상75개의 비교 순위로 변환. 이웃 매칭에서 해당 특징 자체와 자기 샷을 제외한다.
- RF/ET: 각 특징 전문가에서 모델 종류2개×시드2개 평균.
- 부스팅: CatBoost·LightGBM·XGBoost의 사전 고정 설정3개 평균. 외부 평가로 조기종료/튜닝하지 않는다.
- 95번 점수 조정은 학습 정상 점수95분위수 또는 logit 중앙값-IQR 기준이며 확률 보정이 아니다. 학습 정상의 in-sample 낙관성은 최종 내부 구간제외 예측에서 다시 평가한다.

## 완료한 실험96

배럴 온도1~5의 공통 수준 대신 직교 대조의 선형·이차·삼차·사차 모양4개, 배럴-Hopper·배럴-금형·금형 측면 차이3개, slope×curvature 상호작용1개 =8개로 추가 전문가를 구성했다. 센서 번호의 물리적 배치/활성을 확정한 것은 아니며 가스 원인을 진단했다고 주장하지 않는다.

기존 모델의28개 학습ref 및 센서 변환/점수를 캐시에 저장했다. 후속 실험에서도 해당 모델의 학습ref에 평가 구간이 없어야 하며 코호트/시각/그룹 일치를 검증한다. 같은 모델을 재학습할 필요 없이 새 전문가만 학습하고 학습 내부에서 조합을 다시 비교한다.

96번은7개 구간/28개 학습ref 계산을 완료했다. 온도 모양 전문가 자체는 분리력이 없었고 내부 선택에서도 선택되지 않아 전체 결과가94번과 동일했다. 느슨한 F1 최적 임계값에서 가스19개를 모두 잡는 행이 있지만 정상598~599개도 오탐해 F1 약0.060이므로 좋은 결과로 사용하지 않는다. 완료 성적: `tables/rg3_thermal_shape_metrics.csv`.

99번의 top3 전문가만 고정한 절차는 TP7/FP54/FN12/TN547, F1 0.175, AP 0.130이었다. 전체10개 순위 전문가(AP 0.077)보다 순위 분리력은 높아졌으나 F1이나 전체 후보 선택이 안정화된 것은 아니다. 선택 변수는 주로 쿠션·배럴2·배럴5 흔들림의 조건부 순위였다. 중요도 선택은 각 학습ref 안에서만 수행했다.

100번은 품질 라벨을 이동하지 않았다. 센서 이력의 같은history_segment 내 shift1/3 상태6개 + 과거10샷 표준편차4개를 입력했고 미래값/이전 품질 정답은 미사용했다. 검사 지연을 확인한 결과는 아니며 이 가설은 성능에 도움이 되지 않았다.

101번의 물리 확인 가설도 도움되지 않아 주선택이 원래rank75 점수로 돌아갔다. 조건을 단순하게 곱한다고 오탐이 자동 감소하는 것은 아니다. 고정 확인 후보 중11개를 잡은 행은 오탐231개/F1 0.084라 좋은 결과로 사용하지 않는다.

다섯 실험의 모든 후보 혼동행렬을620개 예측에서 직접 재계산했고, 가스19개/중복 시각 없음/F1 수식 및 노트북 실행 오류 없음을 확인했다. 산출물은 `tables/rg3_consensus_gates_*`, `tables/rg3_hard_negative_*`, `tables/rg3_rank_feature_subset_*`, `tables/rg3_causal_lag_state_*`, `tables/rg3_noise_confirmation_*`이다.

### 다음 개발용 고정 후보: F1 0.235

104번의 **normal-CORAL / CN7 전체 / 보조가중.25 / 순위3 / RF·ET2시드 평균**을 고정한 절차는 **TP6/FP26/FN13/TN575, F1 0.235, AP 0.156**이었다. 정상의26/601을오탐했고 예측불량32개 중 실제가스6개였다. 106번의가스방향·CN7전체·부스팅 고정 후보는 TP7/FP34/FN12/TN567, F1 0.233였다.

이 후보들은 학습 내부에서 임계값을 정했지만, 결과를 보고 후속 후보로 고른 행이다. 전체 후보를 자동 선택하는104/106 주결과와 구분해야 한다. 새로운 독립 검증 성공이나 최종 선정 성능으로 주장하지 않는다. F1 0.5는 아직 미달성이다.

[CORAL 원문](https://ojs.aaai.org/index.php/AAAI/article/view/10306)의 whitening/recoloring으로 제품별공분산 차이를 맞추는 핵심을 참고했다. PDF 원문의3.2/Algorithm1을 확인했다. 이 실험은 원문의전체source/target·lambda1 대신 **CN7 정상과RG3 학습정상만**, LedoitWolf+.01I를 사용한label-assisted 변형이다. 평가RG3 자료의공분산은 계산하지 않았다. 가스평균 방향을Householder로맞추는 부분은 자체지도확장이며 CORAL 원문알고리즘/확인된가스물리원인이 아니다. 모든ref에서직교성 및regularized AᵀCsA=Ct 오차를검증했고 최대오차는3.74e-16이었다. 이것은구현수학검증이지 성능보장이 아니다.

108번사후점검에서6개탐지는이전순위75 탐지우선후보의8개에포함됐다. 새가스유형을잡은것이아니라 **2개탐지를잃고오탐을61→26으로줄여F1을높인것**이다. 놓친가스13개를추가로탐지하는작업이여전히필요하다. 전체가스19개/오탐정상26개의시각·점수·임계값·외부모델입력순위는 `tables/rg3_CORAL_all19_gas_casebook.csv`, `tables/rg3_CORAL_false26_casebook.csv`에있다.

### 역사 정보 부족 감사

109번에서 **가스1개/정상10개**는noise3/std4 값이NaN임을확인했다. min_periods5로계산된값도실제10개측정인지110번에서별도확인했고 **가스1개/정상20개**가온전한이전10개측정을갖지못했다. 부족한가스는 **2020-10-23 01:03:33**, 해당센서의이전10개창에실제유효값이2개뿐이었다. 추가11/4 가스2개가std10 역사부족이라는뜻이아니다. 이것은앞서ratio형파생변수의zero분모로인한결측과다른가용성기준이다. 부족한역사를정상중앙값으로채우면학습표현이왜곡될가능성은있지만, 이전실패의원인이라고입증한것은아니다.
