# RG3 독립검증 감사 — 현재 상태

## 결론

**독립 자료에서의 RG3 가스 탐지 개선은 확인하지 못했다.** 현재 제공된 자료에는 새 독립 평가에 쓸 수 있는 미사용·식별 가능한 RG3 RH 라벨이 없다. 알려진 자료를 재분할해 얻은 지표는 개발용이며 독립 검증으로 주장하지 않는다.

## 목표 요구사항별 증거

| 요구사항 | 현재 확인한 증거 | 판정 |
|---|---|---|
| 데이터 출처 및 미사용 라벨 감사 | 현재 data 아래 모든 CSV의 컬럼·SHA256·RG3 RH 시각/설비/제품 키를 대조 | 감사 완료 |
| 독립 후보가 있으면 사전에 모델·피처·임계값 고정 | 이전 추가37개 protocol과 예측 봉인 SHA256을 현재 파일로 재확인, 둘 다 일치 | 사전 기록 무결성 확인 |
| 실제 별도기간 평가 결과 확인 | 추가37개의 실제 정답과 예측에서 2×2 직접 재계산 | 기준·주후보·보조 모두 TP0/FP12/FN2/TN23 |
| 남은 독립 라벨 유무 | 원본628 RH 키 = 기존591 + 이미 개봉37; 현재 다른 식별 가능 라벨 CSV에도 새 RH 키 없음 | 미사용 식별 가능 RH 라벨0 |
| 복사본을 새 자료로 잘못 세지 않음 | ZIP의 CSV4개 바이트 동일, 현재 저장된 로컬 브랜치/ref의 data 내용 대조 | 새 자료 아님 |
| 독립 자료가 없으면 새 라벨 필요성 명시 | 아래 추가 라벨 및 평가 절차 | 명시 완료 |

이는 목표에 명시된 **독립 자료가 없을 때의 감사/증거 제시 경로**를 마친 결과다. 모델 개선에 성공했다거나 F1 목표를 달성했다는 뜻은 아니다.

## 범위와 한계

RH만 사용한다는 기존 결정 유지. LH를 새로운 독립 표본으로 바꾸지 않았다. 비라벨은 정상/가스 정답이 아니며 모델의 의사라벨을 독립 평가 정답으로 삼지 않는다. 시각·설비·제품 정보가 없는 CN7 명칭 파일도 검증된 RG3 독립 라벨로 가정하지 않는다.

감사 범위는 현재 작업공간 파일과 현재 저장된 로컬 브랜치/원격추적 ref 스냅샷이다. CSV22개와 로컬 refs7개를 확인했다. 이 refs의 data 경로에는 추적된 CSV/ZIP이0개여서 거기서 추가 데이터를 발견하지 못했다. 이번에 원격을 새 fetch하지 않았으며 다른 사람이 가진 외부·비공개 자료의 존재까지 부정하지 않는다. 봉인 해시는 현재 파일의 사전 기록 일치를 확인하지만, 과거 비저장 조회가 전혀 없었다거나 센서 자체를 EDA에서 본 적 없었다는 증거는 아니다. 이전37개는 라벨 블라인드 추가기간 검증으로 표현하며 완전히 미관측된 공정 자료라고 과장하지 않는다.

현재 원본 RH628개 중 모델 개발 대상 정상/가스는620개(정상601/가스19)이고 나머지8개는 다른 불량이다. 이미 개봉한37개에는 가스2개·정상35개가 포함되며 이후 개발에 사용했다. 이 37개를 다시 숨겨도 새 독립 자료가 되지 않는다.

## 실제로 필요한 추가 라벨

- 지금 사용한628개 키와 겹치지 않는 RG3 RH 샷 또는 아직 라벨을 확인하지 않은 비라벨 샷에 대한 별도 검사 정답.
- 정상/가스/미성형/기타를 구분할 실제 검사 기록. 모델의 예측을 정답으로 재사용하면 안 됨.
- Timestamp·설비·제품/측면·센서 정의/단위 및 샷 연결 정보. 과거 특징을 쓸 경우 앞선 센서 이력도 필요.
- 가능하면 여러 운전 구간/독립 발생 사건을 포함. 연속 가스 샷만 모으면 표본 수가 많아 보여도 발생 사건은 하나일 수 있음.

새 라벨을 받기 **전에** 개발 후보와 비교 기준, 피처 처리, 임계값, 평가 제외 규칙을 고정한다. 라벨을 숨긴 상태에서 예측을 저장·봉인하고, 그 뒤 한 번 개봉해 TP/FP/FN/TN·탐지율·정밀도·F1을 보고한다. 새 평가 라벨을 보고 피처나 임계값을 바꾸면 이후 결과는 그 자료에 대한 개발 성적이다.
