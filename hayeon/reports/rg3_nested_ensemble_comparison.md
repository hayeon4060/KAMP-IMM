# RG3 가스: 서로 다른 탐지 신호의 중첩 결합

## 핵심 결과

전체583개(정상566·가스17)를 유지한 구간 제외 평가에서 max_union + 학습 정상99% 기준은 TP4/FP6/FN13/TN560, AP0.1686이다. 판정10개 중 실제가스4개(정밀도40%), 전체가스17개 중4개(재현율23.5%)를 찾았다. 기존 std4 고정0.5는 TP1/FP6/AP0.1387이었다.

판정기준 변경 효과를 분리하면: 고정0.5에서 결합은 TP2/FP7이고, 같은 학습보정 기준의 단독 std4는 TP3/FP13이다. 결합의 개선 후보를 기준변경만의 효과 또는 변수추가만의 효과로 설명하지 않는다. 단독 residual4 보정은 TP1/FP0으로 더 보수적이다.

과거구간만 학습한440개(정상427·가스13)에서는 결합 보정 TP2/FP4/FN11/TN423이다. 같은 기준의 std4는 TP2/FP8이므로 발견수는 같고 오탐은4개 적다. 그러나 순위 AP는 결합0.0812로 단독0.1133보다 낮다. 두평가에서 모두 AP가 개선됐다고 주장할 수 없다.

결합 보정으로 찾은 가스는 2020-10-22 04:46:36, 05:10:17 및 2020-10-23 05:15:46, 07:15:11이다. 두날의 두관측구간에 걸쳐 발견했지만13개는 여전히 놓쳤다. 같은62개 검사예산에서는 기존과 결합 모두6개 발견으로 순위검사 예산의 이득은 없다.

반복 탐색에 사용한 동일자료의 중첩검증 결과다. 외부구간 정답으로 임계값을 고르지는 않았지만, 모델 조합 아이디어 자체는 이전 결과를 보고 정했으므로 독립 최종성능이 아니다. 가능성이 있는 후보로 보관하고 향후 새로운 생산기간에서 확인해야 한다.

## 조건

- RH 가스17 + 정상566 전체 유지. 미성형 제외. 같은 RF200/depth8/leaf3/balanced_subsample/seed42.
- 흔들림 RF와 기존 정상관계잔차 RF를 정확히 재현. 잔차4개 중 평균RPM 관련 식은 정의 불확실성이 있어 물리 원인으로 해석하지 않음.
- 결합 후보는 사전 고정 평균, 최대값(OR에 대응), 두점수 로지스틱(C1,balanced)뿐. 단독모델과 같이 보고.
- 바깥 구간을 완전히 제외하고, 결합 학습 점수는 안쪽 구간제외 OOF로 생성. 잔차의 정상 회귀도 각 RF 학습 구간 안에서 다시 학습.
- fixed05는 고정0.5. train_fpr1은 학습 정상의 안쪽 예측 점수99% 분위수보다 큰 점수. 평가 정상 오탐1%를 보장하거나 정확히6개로 강제한 것이 아님.
- 로지스틱 기준 보정은 안쪽 구간을 하나 더 빼고 결합모델 예측을 만들어 사용. 모든 모델선택·분할 방식은 반복 탐색의 영향을 받아 독립 최종 평가로 주장하지 않음.
- 과거구간만 학습 결과는 후반440개/가스13개로 별도 표기. 안쪽 결합학습의 구간분할은 과거 학습집합 내부 교차검증이며 외부 미래구간은 사용하지 않음.
- 상위10%는 각 평가구간별 배치 검사 예산. 실시간 임계값 성능과 별개.
