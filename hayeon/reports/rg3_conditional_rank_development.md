# RG3 가스 고도화: 조건부 정상 순위

## 이번에 나온 개선 후보

RG3 RH 정상601개·가스19개, 같은7개 관측구간 검증에서 기존 비교 모델보다 탐지가 늘어난 후보가 나왔다. **개발 자료의 후보 성적이며 새 독립 검증/최종 선택 성능이 아니다.**

| 설정 | 모델 | 찾은 가스 TP | 정상 오탐 FP | 놓친 가스 FN | 맞힌 정상 TN | F1 |
|---|---|---:|---:|---:|---:|---:|
| 탐지 우선 .10 | 같은 조건 std4 비교 기준 | 3 | 67 | 16 | 534 | 0.067 |
| 탐지 우선 .10 | 조건부 순위75 앙상블 | **8** | **61** | **11** | **540** | **0.182** |
| 중간 .05 | 같은 조건 std4 비교 기준 | 3 | 33 | 16 | 568 | 0.109 |
| 중간 .05 | 정상 점수 단위 보정 순위75 앙상블 | **4** | **22** | **15** | **579** | **0.178** |

첫 후보는 기준이 잡은3개를 모두 잡으면서5개 추가 탐지했다. 둘째는 같은 .05 비교에서 탐지가1개 늘고 오탐은11개 줄었다. 정상 점수 단위 보정이 없는 순위75의 보수적 .02 설정은3개 탐지·19개 오탐(F1 0.146)이었다.

설정 비율은 내부 구간 제외 정상 점수의 임계값 분위수 선택용이며 실제 평가 오탐률 보장이 아니다. 이전 17개 가스에서4개 탐지·6개 오탐인 실험과는 자료 구성 및 절차가 다르므로 직접 최고 기록 비교를 하면 안 된다.

## 무엇이 다른가?

단순히 '쿠션이 크다'가 아니라 **다른9개 센서 특징이 비슷한 정상75개 사이에서 해당 쿠션값은 어느 정도 순위인가?** 를 계산한다. 각 특징 자신은 정상 이웃을 찾는 기준에서 빼고, 학습 정상 자기 자신의 값도 비교 이웃에서 제외한다.

원래 특징10개는 Hopper·배럴2·배럴5·쿠션·계량시간·최대사출압력-전환압력 차이6개와 과거10샷 표준편차4개다. 조건부 순위로 바꾼 후에도 입력10개다. 과거 표준편차는 현재 샷을 넣지 않고 앞선 센서 이력으로 계산한다.

두 후보 모두 **RF·ExtraTrees × 초기화시드42/7 = 모델4개 평균 앙상블**이다. 91번은 각 모델의 점수를 해당 모델이 학습한 정상 점수95분위수(최소.01)로 나눠 점수 크기를 조절했다. 이 값은 확률 보정이 아니며 학습 정상은 in-sample이라 낙관적일 수 있다. 최종 임계값은 반드시 내부 구간 제외 정상 점수에서 정했다.

표현·결측·정상 이웃·척도·분류·임계값 학습에는 외부 평가 구간을 넣지 않았다. CN7는 이번 모든 실험에서 제외했다.

## 추가로 찾은 가스

탐지 우선 후보가 std4 기준에 추가한5개는 다음과 같다.

| 시간 | 라벨 관측 구간 |
|---|---:|
| 2020-10-22 04:46:36 | 3 |
| 2020-10-23 05:59:00 | 5 |
| 2020-10-23 07:21:20 | 5 |
| 2020-11-04 05:17:45 | 6 |
| 2020-11-04 05:18:48 | 6 |

11/4 두 샷은 이전 별도37개 검증 이후 라벨을 확인하고 개발 자료로 사용한 샷이다. 이번 해당 외부 구간을 학습에서는 제외했지만 완전히 새로운 블라인드 검증 성공은 아니다. 관측 구간 번호는 실제 설비 연속운전 Run 확정값이 아니다.

오탐61개 중 구간6에17개가 몰렸다. 이 구간의 정상34개 중17개 오탐이라 여전히 운전 상태가 바뀐 구간의 오탐 억제가 문제다. 다른 구간의 정상도 오탐하므로 구간6만 제외해 지표를 높이면 안 된다.

## 안 된 방법도 기록

- 순위 변수에 LR 두 설정·RBF SVM 두 설정을 평균한 경우: 이웃75/.10에서6개 탐지·58개 오탐, F1 0.145. RF/ET 후보8개·61개보다 탐지가 줄어 주후보로 바꾸지 않았다.
- 학습 가스만2개 군집으로 나눈 전문가: .10에서3개 탐지·60개 오탐. 군집을 나눈다는 이유만으로 좋아지지 않았다.
- std4 전문가와 순위 전문가 최대/평균 합산은 이번 후보보다 낫지 않았다. 여러 모델이라는 이유로 무조건 추가하지 않는다. 후보 자체가 이미4개 모델 앙상블이다.

## 전체 선택 절차는 아직 약함

위 표는 이번 결과를 보고 후속 개발용으로 보관한 고정 설정 후보 행이다. 모델·임계값을 내부 검증으로 자동 선택한 전체 절차는 88번 TP3/FP65/FN16/TN536(F1 0.069), 89번 TP4/FP70/FN15/TN531(F1 0.086), 90번 TP3/FP79/FN16/TN522(F1 0.059), 91번 TP3/FP67/FN16/TN534(F1 0.067)이었다.

따라서 '독립적으로 선정한 최종 모델이8개를 안정적으로 잡는다'고 주장할 수 없다. 좋은 후보 표현은 찾았지만, 후보 선택과 임계값의 구간 간 안정화가 남았다. 정상/가스가 여전히 많이 겹치고 표본도 적다.
