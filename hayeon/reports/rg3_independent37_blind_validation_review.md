# RG3 가스 블라인드 추가검증 — 37개 기록
## 결론
새로 확보한 별도 라벨 기록37개에서 고정 모델을 정답 개봉 전에 예측하고 봉인했다. 가스2개·정상35개였고 **기준·주후보·보조후보 모두TP0/FP12/FN2/TN23, F1=0**이었다.
**독립적인 성능 개선은 확인하지 못했다. 이전 탐색 F1=0.516은 일반화 성능으로 사용할 수 없다.** 현재 자료에서 모델을 더 튜닝할 수는 있지만, 이미 정답을 개봉한37개를 다시 평가하고 독립검증이라고 주장하지 않는다.

## 어떻게 별도 검증 자료를 찾았나
- 원본 data/original/labeled_data.csv의 RG3 RH는628개다.
- 이전 분석·라벨 감사에는591개가 있었고, 그중 정상/가스583개를 모델에 사용했다.
- 나머지37개는2020-11-04~11-05의 S14·RG3 RH 기록이었다. 이전 모델의 라벨 기간은10/21~10/23이다.
- 키(EQUIP_CD,PART_NAME,TimeStamp)가 기존591개와 중복되지 않았고, 저장된 모든 보고서 표에서 해당 시각의 사용 흔적이 없었다.
- 처음에는37개의 시각·제품·설비 메타정보만 열었다. 기존모델/피처/분위수/표결규칙을 protocol JSON으로 고정한 뒤 센서값만 읽어 예측했다.
- 예측파일과프로토콜의SHA256·봉인시각을저장하고, 별도64번노트북에서해시를확인한뒤정답을처음개봉했다.

### 독립성 표현의 한계
이것은 이 실험에서 **라벨 블라인드로 진행한 추가기간 검증**이다. 저장되지 않은 과거 대화형 조회까지 없었다는 절대 증거는 없다. 센서값이 예전 비라벨 원본 이력/EDA에 포함됐을 가능성도 있으므로 모든공정정보가완전히새로운미관측표본이었다고단정하지않는다. 평가 라벨을보고이번예측을맞춘것은아니며, 결과는실패였다. 보장할수없는독립성수준을과장하지않는다.

## 남은 독립 라벨
65번에서원본628개RH키=이전591개+이번37개임을대조했다. **현재 작업공간의원본파일에남은미사용RG3 RH라벨은0개다.**
압축파일의4개CSV는현재data/파일과바이트해시까지동일했다. 다른복사본·시간정보추가파일·로컬원격브랜치data경로에서도새RG3라벨은확인하지못했다. 비라벨자료에정상/가스정답을가정하거나모델예측을정답으로만들어독립F1을계산하지않는다.

## 앞으로 실제로 필요한 것
새로운RG3 RH샷의개별정답을포함한라벨자료또는아직우리분석에노출되지않은공식검증셋이필요하다. 시각·설비·제품·불량사유와센서이력이있어야현재후보를같은조건으로검증할수있다. 불량의경우가스인지미성형인지도구분되어야한다.
다음검증은검증전프로토콜·모델·임계값을다시고정하고,새정답을보지않은상태에서예측을봉인한뒤한번평가한다. 실패한37개를개발자료로사용하더라도다음독립검증표본으로재사용하지않는다.
현재기록만계속돌려서‘독립검증F1≥0.5’를만들수는없다. 목표는미달성이며새로운외부라벨이필요한상태다.
