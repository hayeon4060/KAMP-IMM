# Run 및 run 내부 변화: 브리핑 메모

분석: `notebooks/03_run_and_within_run_eda.ipynb`. 대회 labeled 행을 원본에 연결한 뒤 LH/RH를 샷 단위로 통합했다. 공정값은 한 행을 사용하고 라벨은 둘 중 하나라도 불량이면 불량으로 보존했다. 원본 10/27 초기허용불량은 대회 범위 밖이므로 본 결과에 포함하지 않았다.

## 바로 전달할 수 있는 특징

### 1. CN7은 연속 발생, RG3는 산발 발생

- 대회 2,393행은 1,197샷이다. 불량 42행은 불량 39샷(CN7 14, RG3 25)이다.
- CN7 불량 14샷은 전부 10/16 05:21:38~05:57:20에 발생했다.
- 특히 05:47:24~05:57:20에는 **11샷 연속 불량**이었다. CN7 불량의 78.6%가 이 연속 구간에 해당한다.
- RG3 불량 25샷의 최대 연속 불량 길이는 **1샷**이었다. 같은 시간적 집중 패턴을 보이지 않았다.
- 직전 관측 샷에도 대회 라벨이 있는 경우만 비교하면, CN7은 직전 불량 이후 불량 10/14(71.4%), 직전 정상 이후 불량 4/590(0.68%)였다. RG3는 직전 불량 이후 0/25, 직전 정상 이후 25/560이었다.
- 이 수치는 한 번의 CN7 연속 사건에 크게 의존한다. 일반적인 불량 전이확률로 확정하지 않는다. 직전 불량 라벨은 최종 검사 이전에 알 수 있는지도 별도로 확인해야 하며 기본 모델 입력에서 제외한다.

**브리핑 표현:** “CN7은 불량이 한 번 발생하면 연속되는 구간이 있었고, RG3는 같은 패턴이 없었습니다. 제품별 시간 피처를 따로 봐야 합니다.”

### 2. 금형 온도의 차이는 비교 구간을 맞추면 거의 사라진다

CN7의 정상 전체를 비교 대상으로 삼으면 불량 샷의 온도가 높다. 하지만 불량이 발생한 10/16 관측 구간의 정상 샷만 비교하면 차이가 매우 작아진다.

| 변수 | CN7 전체 정상 평균 | 10/16 같은 관측 구간 정상 평균 | 불량 평균 |
|---|---:|---:|---:|
| Mold_Temperature_3 | 23.33 | 25.02 | 25.07 |
| Mold_Temperature_4 | 24.85 | 27.61 | 27.66 |
| T4 − T3 | 1.52 | 2.59 | 2.59 |
| Plasticizing_Position | 68.591 | 68.842 | 68.844 |
| Max_Back_Pressure | 37.938 | 37.165 | 37.179 |

온도 3의 평균 차이는 +1.74에서 +0.052, 온도 4는 +2.81에서 +0.047로 줄었다. 금형 온도 차이도 해당 구간 정상과 불량에서 사실상 같았다. 따라서 기존 전체 비교에서 보인 온도·계량 위치·배압의 관계에는 생산 시점의 기본 조건 변화가 섞여 있다.

**브리핑 표현:** “불량 온도가 높아 보였지만 같은 시간대 정상도 비슷했습니다. 전체 상관관계만으로 온도를 원인으로 지목하기 어렵습니다.”

이는 관측된 샘플에 대한 비교다. 라벨 없는 샷은 정상으로 가정하지 않았고, 동일 관측 구간은 실제 생산 run과 같다고 가정하지 않았다.

### 3. CN7 미성형 3샷에서는 사출속도 상승과 충전시간 단축이 함께 나타난다

| 시각 (10/16) | 샷 상태 | 최대 사출속도 | 충전시간 |
|---|---|---:|---:|
| 05:54:21 | 가스 | 55.8 | 4.46 |
| 05:55:21 | 미성형 | 60.7 | 4.33 |
| 05:56:22 | 가스·미성형 | 60.9 | 4.33 |
| 05:57:20 | 가스·미성형 | 60.8 | 4.33 |
| 05:58:20 | 정상 | 55.6 | 4.46 |

세 미성형 샷은 최근 10개 이전 관측 샷 중앙값보다 사출속도가 약 +5.15~+5.40 높고 충전시간은 약 −0.13 짧았다. 05:55:21 첫 상승은 직전 샷 대비 약 +4.90이었다.

**브리핑 표현:** “CN7 연속 가스 불량 구간 끝에서 3샷 동안 속도가 급상승하고 충전시간이 짧아지며 미성형이 나타났습니다. 다음 샷에서 값과 라벨이 정상으로 돌아왔습니다.”

속도 변경이 원인인지, 불량을 보정하기 위한 작업자 조치인지, 측정 결과인지 알 수 없다. 세 샷만의 사건이므로 재현 여부 확인이 필요하다.

### 4. ‘미성형이면 속도가 높다’는 특징은 RG3에 그대로 적용되지 않는다

| 제품 | 미성형 샷 수 | 정상 속도 중앙값 | 미성형 속도 중앙값 | 정상/미성형 충전시간 중앙값 |
|---|---:|---:|---:|---:|
| CN7 | 3 | 56.0 | 60.8 | 4.43 / 4.33 |
| RG3 | 8 | 128.2 | 128.25 | 0.94 / 0.94 |

CN7에는 큰 속도 변화가 있지만 RG3 미성형 샷의 중앙값은 정상과 거의 같다. 동일 샷에 가스·미성형 라벨이 함께 있을 수 있어 유형별 샷 수를 합하면 전체 불량 샷 수보다 커질 수 있다.

**브리핑 표현:** “속도 상승과 미성형의 관계는 CN7의 특정 사건에서 강했고 RG3에는 약했습니다. 제품별로 검증해야 합니다.”

### 5. 라벨 파일의 빈 구간은 실제 run 중단을 뜻하지 않는다

- 라벨 파일만 30분 초과 공백으로 나누면 관측 구간은 CN7 2개, RG3 5개다.
- S14 설비의 모든 제품 생산 이력을 함께 연결하면, 제품 변경 또는 30분 초과 관측 간격으로 추정한 run은 대회 라벨이 있는 범위에서 CN7 1개, RG3 3개다.
- CN7은 10/16 03:51:20~10/20 06:20:14까지 이어지는 후보 run에 두 라벨 관측 구간이 모두 들어간다. 기록상 최대 내부 간격은 121초다. 라벨 없는 기간에도 관측된 생산 이력이 있었다.
- 5·10·30·60분 기준에서 CN7은 모두 1개, RG3는 4·4·3·2개로 나뉜다. RG3 run 개수는 기준에 민감하다.
- run 로그나 설정값 이력은 없으므로 실제 현장 run으로 확정할 수 없다. 같은 제품으로 계속 생산하면서 설정이 바뀌었다면 이 후보 run 안에 서로 다른 조건 구간이 있을 수 있다.
- CN7은 대회 라벨이 있는 후보 run이 하나뿐이다. **현재 샘플로 CN7의 run 사이 불량률 차이나 새 run에서의 일반화 성능을 검증할 수 없다.**

**브리핑 표현:** “run 구분은 라벨 데이터만으로 하면 잘못될 수 있습니다. 전체 시간 이력과 제품·설정 변경을 함께 봐야 합니다.”

### 6. RG3에서는 최근 배럴 온도 변동폭이 추가 후보다

RG3의 Barrel_Temperature_5 직전 10샷 표준편차 중앙값은 정상 약 0.294, 불량 약 0.356이었다. 현재 값도 정상 중앙값 265.0, 불량 265.1로 약간 높았다. 최근 변동폭은 3개 후보 run 중 2개에서 불량 쪽이 컸고, 나머지 1개에서는 반대였다.

이 표준편차 비교에는 이전 관측 5개 이상이 있는 정상 562샷·불량 24샷이 사용됐다. 동일 데이터에서 탐색한 값이며 검증 성능이 아니다.

**브리핑 표현:** “RG3는 절대 속도보다 최근 온도 흔들림이 후보로 보였지만 모든 run에서 일관되지는 않았습니다. 다음 검증 대상으로 두겠습니다.”

## 추가 확인: 같은 run에서 시간이 지나면 온도가 오르는가?

`04_run_temperature_trends.ipynb`에서 원본의 전체 생산 이력을 이용해 확인했다. 센서 온도는 10분 단위 중앙값으로 요약했고, 초반·후반 비교는 각각 최초·마지막 30분의 중앙값이다. 아래 구간은 실제 설정 로그가 없는 후보 run이다.

| 후보 run | 길이 | 금형 온도 3: 초반 → 후반 | 금형 온도 4: 초반 → 후반 |
|---|---:|---:|---:|
| RG3 10/23 01:01 시작 | 1.58시간 | 21.4 → 22.0 (+0.6) | 22.7 → 23.4 (+0.7) |
| RG3 10/23 03:12 시작 | 4.56시간 | 22.7 → 23.6 (+0.9) | 24.1 → 25.2 (+1.1) |
| CN7 10/16 03:51 시작 | 98.48시간 | 24.8 → 23.6 (−1.2) | 27.5 → 24.7 (−2.8) |

- RG3 10/23 두 구간은 금형 온도가 경과 시간에 따라 상승했다. 10분 중앙값과 시간의 Spearman 상관은 온도 3 기준 약 0.99와 0.97이었다. 이는 구간 안의 추세 설명이며 독립 표본 검정이나 예측 성능이 아니다.
- CN7은 초반 약 24.8에서 25.0~25.2까지 올랐지만, 약 5시간 뒤에는 24.2까지 내려갔다. 전체 후보 run에서도 계속 상승하지 않았다.
- RG3 10/20 시작 구간은 초반 금형 온도 3이 22.8에서 약 5시간 뒤 21.0 수준으로 하락했다. 모든 run이 가열되는 패턴은 아니다.
- 배럴 온도는 상승한 RG3 구간에서도 대체로 일정했다. RG3 10/23 03:12 구간의 배럴 1 초반·후반 차이는 약 +0.1, 배럴 5는 +0.2였다. 금형 온도의 상승과 모든 센서의 상승을 구분해야 한다.
- CN7 긴 후보 run에는 10/17 사출시간·사이클시간의 큰 변화도 들어 있다. 제품·시간 공백만으로 나눈 run이 조건 변경을 충분히 반영하지 못할 가능성이 있다.

**브리핑 표현:** “일부 RG3 구간에서는 같은 제품을 계속 생산하는 동안 금형 온도가 점진적으로 올랐습니다. 반면 배럴 온도는 거의 일정했고, 다른 구간에서는 금형 온도가 내려갔습니다. 현재 온도와 함께 최근 상승 속도와 시작 시점 대비 변화량을 보겠습니다.”

추천 온도 피처는 직전 10·30분 온도 기울기, 초반 관측 기준 온도 대비 변화량, 최근 온도 변동폭이다. run 초반 기준값은 실제 예측 시점에 관측이 완료된 자료만 사용한다. 온도 상승이 불량 증가로 이어지는지는 아직 별도 검증이 필요하다.

그림: `reports/figures/run_temperature_first6hours.png`, `run_temperature_full_trends.png`. 표: `reports/tables/run_temperature_trends.csv`, `run_temperature_early_stages.csv`, `run_temperature_first_hour_summary.csv`.

## 파생 피처의 우선순위

1. 제품별 직전 샷 변화량: 사출속도·충전시간·압력·온도.
2. 같은 후보 run의 직전 10샷 중앙값 대비 편차. 직전 5·20샷도 비교.
3. 직전 샷들의 표준편차·추세. CN7과 RG3의 후보를 따로 검증.
4. 제품 변경 또는 긴 기록 공백 후 경과 시간. 관측 순번은 실제 생산 샷 순번과 구분.
5. 속도 상승과 충전시간 단축이 동시에 나타나는 정도. 현재 값과 과거 값만 사용.

run_id는 분석·분할용으로 둔다. run 전체 평균·불량률·Reason·사후 검사 라벨·ERR_FACT_QTY는 실시간 모델 입력에 넣지 않는다. 회귀·상관 검정의 표본 단위는 중복 LH/RH 행이 아닌 샷으로 둔다. CN7 연속 사건의 샷들도 독립적인 14개 사건이라고 해석하지 않는다.

## 변수 의미와 데이터 품질

- 대회 범위 1,197샷 전부에서 Average_Screw_RPM > Max_Screw_RPM, Average_Back_Pressure > Max_Back_Pressure였다. 명칭의 일반적인 최대/평균 관계와 맞지 않는다. 실제 단위·필드 매핑이 확인되기 전에는 차이나 비율을 물리적 효율·부하라고 해석하지 않는다.
- 원본 Cushion_Position 중앙값은 CN7 653.41, RG3 654.25다. 현재 자료만으로 실제 잔류 수지량이나 절대 스크류 좌표라고 확정할 수 없다. 제품별 쿠션 비율의 물리적 의미도 확인이 필요하다.
- 전체 S14 시간 이력에서 같은 설비·시각에 제품이 둘 이상 기록된 17개 시각은 제외했다. 대회 범위 시각에는 해당하지 않는다.
- 같은 설비·제품·시각의 공정값이 원본 행 사이에서 다른 112개 그룹은 시간 경계 정보만 남기고 센서값을 과거 피처 계산에서 제외했다. 대회 1,197샷에서는 이러한 공정값 충돌이 없었다.
- 원본과 대회 파일의 모든 공정변수는 아핀 변환 관계 및 라벨 일치를 검증했다. run 경계 민감도, 라벨 보존, 과거값만 사용한 rolling 계산도 노트북에서 검사했다.
