# CN7 외부 방법 적용 — 정상 학습 및 중첩 구간검증

내부 선택에 사용할 학습 구간에 해당 불량이 0개인 경우에는 F1 최적화를 하지 않고 diverse_mean 모델과 내부 정상 점수 99% 임계값을 사용한다. 나머지 경우에는 내부 구간검증 F1으로 선택한다. 이 규칙을 포함한 primary_inner_selected가 주 결과다. 개별 후보의 외부 점수를 보고 최고를 선택한 성적은 탐색 결과다.

기존 CN7 713 Shot에서 정상694+가스13, 정상694+미성형3, 정상694+초기5, 정상694+전체불량19를 각각 평가. 가스·미성형 혼합 Shot2개는 가스/미성형 각각의 평가에서 양성으로 포함. 다른 불량은 해당 평가에서 제외. RH/LH 중복 Shot을 다시 늘리지 않았다.

3개 observation block 외부검증과 2개 내부구간검증. 연속 설비 run 확정값이 아닌 기존 관측 구간이다. 모든 정규화·공분산·신경망·점수 기준은 학습 정상만 사용. 임계값/모델 선택은 내부 OOF만 사용. 외부 불량 학습 및 Timestamp 중복 0. 이미 반복 열람한 자료라 새 데이터 독립검증은 아니다.

22개 원본 센서 후보에서 학습 정상 상수만 제거. Average_Screw_RPM은 기존 단위 이슈로 제외. 센서 입력은 위 노트북 cols에 명시.

Mahalanobis는 원본 역행렬 대신 LedoitWolf 축소 공분산. VAE는 22→15→5→mu/logvar 2→5→15→22, MSE+0.01 KL,80epoch,정상만 학습. 평가는 eval 및 잠재 평균으로 결정론적 복원. IF150트리,OCSVM nu.01,LOF20이웃. 합의는 4개(IF/SVM/LOF/VAE) 학습 정상99% 기준 통과 수 1~4; 원본 AE 합의를 수정 VAE로 대체한 비교이며 원본 성적의 재현은 아니다.
