# 비라벨 학습 구간 · 비지도 모델 탐색

**질문**: 비라벨 데이터(`unlabeled_data.csv`, 비가동 제외 209,732샷 · 44개 설비×제품 흐름)의 **어느 부분으로** 무엇을 학습하면
라벨 데이터의 불량을 가장 잘 찾는가.

- 학습에는 라벨을 쓰지 않음 (5단계 준지도 트랙만 예외, 별도 표기)
- 채점: 공식 기간(대회 2차 행, CN7 1,211/17 · RG3 1,182/25) = **선택용**,
  추가 기간(CN7 2,745/11 · RG3 71/7, 비라벨 데이터가 끝난 뒤) = **확인용**
- 기준: 현 제출 모델(`final/`, 우진2·09-01 이후·인과 변수 17개·Mahalanobis) — 이 폴더에서 AP 0.373 / 0.791 그대로 재현

## 실행

```bash
python s0_build_cache.py   # 비라벨 전 흐름 파생변수 캐시 (약 15분, 14코어)
python s1_slices.py        # 1단계 구간 탐색 (약 2분)
python s2_models.py 14     # 2단계 모델 23종 × 변수 4종 × 구간 9개 (약 20분)
python s3_selfsup.py       # 3단계 자기지도 사전학습·순서 모델·Dual-model (약 20분)
python s5_semisup.py       # 5단계 준지도 (FixMatch/FreeMatch/ATSSL식, 약 10분)
python s4_validate.py      # 4단계 통합·탐색 보정·부트스트랩
python s4b_finalists.py    # 4b 최종 후보 시드 5개·paired 부트스트랩·운용점
```
데이터는 `../final/data/dataset/`, 전처리 산출물은 `../final/outputs/intermediate/`를 읽는다. 결과는 `outputs/`(git 제외).

## 결론

### 1. 어느 비라벨 구간이 좋은가 — "같은 설비·같은 제품"이면 충분, 넓히면 나빠짐 (CN7, 모델 고정)

| 학습 구간 | 샷 | 공식 AP | 추가 AP |
|---|---|---|---|
| 현 제출: 우진2·CN7·09-01 이후 | 5,179 | 0.373 | 0.791 |
| 우진2·CN7 전체 기간 / 이전·직전 N주·하반기·저불량 로트·Run 시작 제외 등 22개 | 360~8,007 | **0.33~0.38** | 0.68~0.88 |
| 우진2·CN7 4월만 | 1,272 | 0.143 | 0.744 |
| 같은 제품·다른 설비(550톤 도시바)만 | 8,692 | 0.218 | 0.856 |
| 상대 제품(RG3)만 | 13,473 | 0.171 | 0.856 |
| 전 설비·전 부품 | 209,732 | 0.220 | 0.856 |

- 같은 설비·같은 제품이면 기간·정제와 무관하게 거의 같은 값. 표본 1,000샷이면 포화 (1k~20k 모두 0.372).
- 다른 설비·부품을 섞으면 공식 AP가 0.22로 떨어짐. 추가 기간 AP는 오히려 오르지만, 추가 기간 불량 11개 중 10개는
  거의 모든 설정이 상위 5%에서 잡는 '쉬운' 불량(초기허용불량)이라 변별력이 낮음.
- 로트 불량 수(ERR_FACT_QTY)로 '깨끗한' 로트만 고르거나 트리밍해도 효과 없음.

### 2. 어떤 변수·모델이 좋은가 (CN7)

- **변수**: 전 변수 인과 편차 21개 + 물리 관계 편차 5개(`dev26`)가 제출 17개(`c17`)보다 공식 AP가 높음.
  원값(`raw21`)은 기간이 바뀌면 무너짐 (0.01~0.25).
- **모델**: 밀도·거리·재구성 계열(GMM, Mahalanobis, OCSVM, Deep SVDD, AE/DAE/VAE, kNN5)은 모두 0.44~0.47 천장에서 비슷.
  축 분할·변수별 계열(IsolationForest, HBOS, ECOD)은 0.21~0.24 — 변수 사이 관계가 깨진 불량을 못 봄.
- **생성 모델(WGAN-GP critic, GAAL)은 실패**: 공식·추가 모두 무작위 이하. critic 값은 학습 분포 밖에서 임의로 외삽되어 이상 점수가 아님.
  Dual-model(정상 세분화 → VAE+WGAN 가중 앙상블)도 WGAN 쪽 때문에 실패, VAE 부분만 0.17~0.42로 불안정.
- **자기지도 사전학습(DINOv2식, 표형 버전)**: 사전학습 풀을 넓힐수록 MFM 점수가 나빠짐(같은 제품 0.336 → CN7+RG3 0.262 → 전 부품 0.161).
  SCARF+head는 0.37~0.38로 현 제출 수준. 비라벨을 '많이' 쓰는 것보다 '같은 공정 흐름'을 쓰는 것이 중요.
- **순서 모델**: 1D-CNN 윈도우 AE(상대 변수) 0.40~0.41, GRU 예측 오차 0.26~0.32.

### 3. 탐색 보정·최종 후보 (CN7)

설정 1,049개 탐색의 최고 AP를 라벨 순환 이동(사건 군집 보존) 1,000회 귀무분포와 비교:
CN7 공식 최고 0.467 vs 귀무 최고 95% 0.282 (p=0.003) → **CN7 신호는 진짜**.

최종 후보 (시드 5개 평균, ΔAP는 현 제출 대비 paired 부트스트랩 95% 구간, 운용점 = 학습 구간 점수 99.9% 분위 이상 경보 — 라벨 미사용):

| 설정 (구간 · 변수 · 모델) | 공식 AP | 추가 AP | 공식 ΔAP | 추가 ΔAP | 운용점 F1 공식 / 추가 |
|---|---|---|---|---|---|
| 현 제출: cur_0901 · c17 · Mahalanobis | 0.373 | 0.791 | — | — | 0.414 / 0.690 |
| cur_0901 · dev26 · Mahalanobis | 0.446 | 0.579 | +0.073 [0.022, 0.154] | −0.211 [−0.336, −0.016] | 0.414 / 0.741 |
| **w2_all · dev26 · GMM(2)** | **0.453** | 0.702 | +0.081 [0.025, 0.170] | −0.089 [−0.207, 0.000] | **0.452 / 0.800** |
| w2_H2 · dev26 · GMM(2) | 0.465 | 0.596 | +0.092 [0.031, 0.188] | −0.195 [−0.323, 0.000] | 0.444 / 0.645 |
| w2_pre · dev26 · Deep SVDD (시드 0에서 1위) | 0.424±0.025 | 0.559±0.106 | +0.058 [−0.005, 0.192] | −0.195 | 0.499 / 0.629 |
| cur_0901 · dev26 · OCSVM | 0.441 | 0.790 | +0.069 [0.018, 0.151] | −0.001 | 0.353 / 0.220 (경보 과다) |

**권장(조건부)**: 우진2 CN7 전체 기간 정상 + `dev26` + GMM 2성분.
공식 AP와 두 기간 운용점 F1이 모두 오르고(같은 TP를 더 적은 경보로) 시드 편차가 0.001로 안정적.
단, 아래 한계 때문에 "확실한 개선"이라고 말하기는 어렵다.

- 공식 AP 상승은 거의 전부 **10/16 05:45~05:54 가스 불량 샷(한 사건)**의 순위가 오른 것. 단서는 c17에 없는 호퍼온도·배럴2 온도·계량 관계 편차.
  독립 사건이 아니라 한 사건을 더 일찍 감지한 것이고, 운용점(99.9%) 경보 TP는 그대로(6)다.
- 추가 기간 AP는 dev26 계열이 모두 낮아짐. 이 후보는 두 기간을 다 보고 골랐으므로 추가 기간도 더는 깨끗한 확인용이 아님.

### 3-1. 평가 샷이 비라벨에 섞여 있는 문제 — 확인 결과 영향 없음 (보고서 기재 전 팀 확인 필요)

비라벨 CN7 원본에는 평가 기간 샷이 들어 있다: 10/16 하루 1,214샷(2,427행), **공식 라벨 샷 606개 전부**가 시각·공정값 21개까지 일치.
제출 모델과 이 탐색은 학습 전에 라벨 샷 시각 + 라벨 Run 앞뒤 60분을 제거하므로 학습 후보에 남은 라벨 샷은 0개
(남은 10/16 샷 901개는 라벨 샷과 최소 60.5분 간격). 다만 사건 당일 다른 시간대·이후 날짜의 정상 샷은 들어간다(제출 모델의 09-01~11-30도 동일).

학습 구간을 사건 이전으로 엄격히 잘라 다시 계산 (`outputs/leak_check_cn7.csv`):

| 학습 구간 (우진2 CN7) | 샷 | c17+Maha 공식 AP | dev26+GMM(2) 공식 AP | GMM 상위 3% 잡은 불량 행 |
|---|---|---|---|---|
| 전체 기간 (위 표) | 8,007 | 0.373 | 0.454 | 10 |
| 전체 − 10/16 하루 | 7,106 | 0.374 | 0.448 | 9 |
| 10/16 이전 전체 | 4,288 | 0.379 | 0.440 | 8 |
| 09-01~10/15 | 1,460 | 0.375 | 0.445 | 9 |
| 직전 8주 (10/16 이전) | 1,759 | 0.379 | 0.454 | 10 |

결론은 같은 날·미래 샷 덕분이 아니다. 보고서에는 '10/16 이전' 기준 수치를 쓰는 것을 권장.

### 4. RG3 — 어떤 비라벨 구간·모델로도 신호 없음

구간 33개 × 모델 23종 × 변수 4종 + 자기지도·순서·Dual-model 전부 공식 AP 0.02~0.06 (무작위 0.021).
탐색 보정 p=0.81. RG3 불량(가스 22·미성형 10)은 기록된 공정변수에 흔적이 없다는 기존 결론(정보 상한)을 재확인.

### 5. 준지도 트랙 (라벨 사용, 기간 블록 교차)

| 학습 → 채점 | 지도 RF | 지도 MLP | FixMatch | FreeMatch | ATSSL식 | 무작위 |
|---|---|---|---|---|---|---|
| CN7 공식 → 추가 | 0.015 | 0.003 | 0.002 | 0.002 | 0.002 | 0.004 |
| RG3 공식 → 추가 | 0.141 | 0.163 | 0.145 | 0.099 | 0.096 | 0.099 |
| RG3 추가 → 공식 | 0.030 | 0.026 | 0.021 | 0.022 | 0.026 | 0.021 |

적응 임계값(FreeMatch·ATSSL식)은 의사 라벨 불균형은 고치지만, 기간마다 불량 유형이 달라(공식 = 가스·미성형 사건, 추가 = 초기허용불량)
라벨로 배운 패턴이 다른 기간으로 넘어가지 않는 문제는 못 고친다. 같은 조건에서 CN7 비지도 모델의 추가 기간 AP는 0.70~0.88.
(CN7 추가 → 공식은 초기허용 제외 시 학습 불량 1개라 생략.) ATSSL식은 공개 설명을 바탕으로 한 구현이며 논문 코드가 아니다.
