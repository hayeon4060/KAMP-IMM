## 학습 규칙 (이전과 같음)
- 라벨 없는 데이터만 학습. `../unsup_search/common.py` 캐시 정제 규칙(비가동 제외, 라벨 쇼트·라벨 Run ±60분 제외, Run = 60분 공백, 10쇼트 미만 제외).
- 모든 파생변수는 같은 Run의 과거(+현재) 쇼트만 사용. 라벨 쇼트도 같은 함수.
- 전처리: 학습 구간 중앙값·IQR → ±20 클리핑 → 결측 0, 학습 구간 상수 열 제거.
- **기본 학습 구간 = W1: 우진2·같은 제품·라벨 시작 이전** (CN7 < 10/16, RG3 < 10/21). 확인용: w2_all(우진2·같은 제품 전체), eq_all(같은 제품 전 설비), W2(w2_all − 평가일).
- 라이브러리 계산 범위: 우진2 CN7·RG3 + 같은 제품 다른 설비 (전 부품 풀은 이전 탐색에서 일관되게 나빠 제외).

## 판정 (고정)
**CN7 '현 제출 대비 개선'** — 모두 만족 (후보의 W1 설정 기준):
1. 공식 ΔAP(대 R0) 부트스트랩 95% 하한 > 0 (R0도 W1 = cur_0901 ∩ 10/16 이전)
2. 추가 AP ≥ R0(main) 추가 AP − 0.05 = 0.741
3. W2 재학습에서도 공식 AP > R0 W2 공식 AP
4. 탐색 보정 p < 0.05
같은 기준을 R1·unsup_search3 1위 대비로도 판정.
**RG3 '신호 있음'**: 공식 탐색 보정 p < 0.05 그리고 그 설정의 추가 AP > 2×유병률.
