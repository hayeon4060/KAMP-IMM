## 3단계: 계열 전진 선택 (기간 교차)
- 구간 w2_all, 모델 gmm2·maha_lw·knn5. dv26에서 시작해 17계열을 하나씩 더하며, 기준 기간 AP가 가장 오르는 계열을 추가 (오르지 않으면 정지).
- 기준 A = 공식 AP로 고르고 추가 AP 보고 / 기준 B = 추가 AP로 고르고 공식 AP 보고. 두 방향의 '고른 쪽 → 다른 쪽' 값이 일반화 추정.

## 4단계: 최종 후보
- 후보 = 제품별 (공식 AP 상위 5) ∪ (두 기간 lift 기하평균 상위 5) ∪ (3단계 선택 결과).
- 후보 묶음·구간에 AE·Deep SVDD 추가(시드 5), GMM 시드 5 평균.
- 엄격 학습 구간 W1 = 라벨 시작 이전(CN7 10/16, RG3 10/21) 같은 제품·우진2, W2 = 전체 − 평가일로 다시 학습해 유지되는지 확인.
- 현 제출(R0: cur_0901·c17·maha_lw, 공식 0.373/추가 0.791)과 이전 탐색 최고(R1: w2_all·dev26·gmm2, 0.453/0.702) 대비 paired 부트스트랩 ΔAP(사건 군집 보존 없이 행 단위, 500회).

## 5단계: 탐색 보정·지표
- 제품·기간별로 2~4단계 모든 설정의 최고 AP를, 라벨 순환 이동 1,000회(시간순, 이동량 n/20~n−n/20 균등)의 '전 설정 최고 AP' 분포와 비교 → p.
- 보조 지표: 검사량 0.8%·1.65%·5%에서 잡은 불량 행 수, RG3는 상위 5%에 든 불량의 서로 다른 시간대(1시간 단위) 수.

## 판정 (고정)
**CN7 '현 제출 대비 개선'** — 모두 만족:
1. 공식 ΔAP(대 R0) 부트스트랩 95% 하한 > 0
2. 추가 AP ≥ R0 추가 AP − 0.05 (= 0.741 이상, 비열등)
3. 엄격 W1 학습에서도 공식 ΔAP(대 R0, 같은 W1) > 0
4. 탐색 보정 p < 0.05 (공식)
같은 기준을 R1 대비로도 따로 판정 ("이전 탐색 최고 대비 개선").

**RG3 '신호 있음'** — 공식 AP 탐색 보정 p < 0.05 **그리고** 그 설정의 추가 AP > 2 × 유병률(0.197).

**권장 설정**: 판정을 통과한 것 중 두 기간 lift 기하평균 최고. 통과가 없으면 "개선 없음"으로 보고.
