# 협업 방법

## GitHub 사용

### 처음 한 번
```bash
git clone <주소> kamp_injection
cd kamp_injection
conda create -n kamp python=3.11 -y
conda activate kamp
pip install -r requirements.txt
python -m ipykernel install --user --name kamp --display-name "kamp"
python src/check_env.py
```

### 작업할 때마다
```bash
git checkout main
git pull                                   # 남이 올린 것 받기
git checkout -b explore/이름-주제           # 새 브랜치
jupyter notebook                           # 작업
git add . && git commit -m "[탐색] 금형온도 하루 추이"
git push origin explore/이름-주제
```
그 다음 GitHub 웹에서 Pull Request 를 만들고 팀에 알린다.

### 커밋 메시지 규칙
```
[탐색] 무엇을 봤는지
[전처리] 무엇을 바꿨는지
[모델] 무엇을 돌렸는지
[문서] 무엇을 적었는지
```

### 주의
- `data/raw/` 는 git 에 안 올라간다 (.gitignore). 각자 KAMP에서 받아 넣는다.
- 노트북은 각자 파일로 만든다. 같은 파일을 둘이 고치면 충돌이 심하다.
- main 에 직접 push 하지 않는다.

## Confluence 를 쓴다면
GitHub 는 코드와 그림, Confluence 는 **회의록과 결론**으로 나누는 게 깔끔하다.

| 내용 | 어디에 |
|---|---|
| 코드, 노트북 | GitHub |
| 그림 파일 | GitHub (reports/figures) |
| 발견 한 줄 기록 | GitHub (docs/findings.md) |
| 회의록 | Confluence |
| 역할 분담, 일정 | Confluence |
| 보고서 초안 | Confluence |

그림을 Confluence 에 붙일 때는 GitHub 링크가 아니라 파일을 직접 업로드한다.
(private 저장소면 링크가 안 열린다)

## 노트북을 git 에 올릴 때
출력이 잔뜩 들어가면 diff 가 지저분해진다. 커밋 전에 출력을 지우거나:
```bash
pip install nbstripout
nbstripout --install        # 저장소에서 한 번만
```
이러면 커밋할 때 자동으로 출력이 빠진다. (그림은 reports/figures 에 따로 저장하므로 문제없다)
