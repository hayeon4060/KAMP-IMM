# 사출 공정과 24개 변수

## 1사이클 순서
```
형체결(닫기) → 사출(충전) → 절환 → 보압 → 냉각 ┬ 계량(스크류 회전·후퇴)
                                                 └ 형개(열기) → 취출 → 다시 닫기
```
계량은 냉각과 **겹쳐서** 진행된다. 앞 제품이 식는 동안 다음 발을 모은다.

## 스크류의 두 가지 움직임
| 단계 | 회전 | 직선 |
|---|---|---|
| 사출 | 없음 | 빠르게 전진 |
| 보압 | 없음 | 아주 천천히 전진 |
| 계량 | **있음** | 천천히 후퇴 |

회전과 전진은 절대 동시에 일어나지 않는다.

## 왜 보압이 필요한가
- 수지가 굳으면서 부피가 **25% 줄어든다**
- 가압으로 미리 더 넣을 수 있는 건 **15%뿐**
- 모자란 10%를 식는 동안 계속 보충하는 것이 보압
- 게이트가 굳으면 더 못 넣으니 거기서 끝난다

## 단계별 변수
| 단계 | 변수 | 의미 | 이상 시 |
|---|---|---|---|
| 형체결 | Clamp_Close_Time | 닫고 조이는 시간 | 조임 부족 → 플래시 |
| 충전 | Filling_Time | 캐비티를 채우는 시간 | 길면 유동 중 고화 → 미성형 |
| 충전 | Max_Injection_Speed | 스크류 전진 속도 | 낮으면 충전 부족 |
| 충전 | Max_Injection_Pressure | 충전 중 최대 압력 | 상한에 붙으면 = 밀어넣기 힘들었다는 신호 |
| 절환 | Max_Switch_Over_Pressure | 충전→보압 전환 시점 압력 | 낮으면 덜 찬 채 전환 → 미성형 |
| 보압 | Cushion_Position | 보압 끝 스크류 잔량 | 0이면 보충할 재료 없음 |
| 계량 | Plasticizing_Time | 다음 쇼트분 모으는 시간 | 길면 체류↑ → 열분해 → 가스 |
| 계량 | Plasticizing_Position | 계량 완료 위치 | 부족하면 다음 쇼트 충전 부족 |
| 계량 | Max/Average_Screw_RPM | 스크류 회전수 | 높으면 전단발열 → 가스 |
| 계량 | Max/Average_Back_Pressure | 계량 중 거는 저항 | 낮으면 공기 혼입, 높으면 발열 |
| 가열 | Barrel_Temperature_1~6 | 노즐(1)→호퍼(6) 구간 온도 | 낮으면 점도↑ → 미성형, 높으면 열분해 → 가스 |
| 가열 | Hopper_Temperature | 투입구 온도(건조) | 낮으면 수분 → 가스 |
| 냉각 | Mold_Temperature_3,4 | 금형 온도 2채널 | 낮으면 빨리 굳음 → 미성형 |
| 형개 | Clamp_Open_Position | 여는 거리 | 비정상값 = 설비 이상 |
| 전체 | Injection_Time | 사출 전체(충전+가압+보압) | Filling과의 차이가 보압 구간 |
| 전체 | Cycle_Time | 1사이클 총 시간 | |

## 불량 세 가지의 메커니즘
**가스**: 실린더 안 체류가 길거나 온도가 높으면 수지 사슬이 끊어져 기체가 생긴다.
수분도 원인. 생긴 가스가 금형의 **벤트**(0.01~0.03mm 얕은 홈)로 빠지면 문제없지만,
벤트가 막히면 표면에 은백색 줄(가스 마크)이나 내부 기포가 된다.
→ 벤트는 캐비티마다 따로 있어서 한쪽만 막힐 수 있다. RG3 RH 편중의 설명.

**미성형**: 수지가 캐비티를 다 못 채운 것. 온도가 낮아 점도가 높거나, 압력이 부족하거나,
유동 중에 먼저 굳어서 생긴다. "양이 모자라서"가 아니라 "제때 도달 못해서"인 경우가 많다.

**초기허용불량**: 기동 직후 금형·배럴이 아직 열평형에 도달하지 않은 구간의 불량.
현장에서는 정상으로 간주하고 버린다. 당일 26~30번째 쇼트에 집중.
