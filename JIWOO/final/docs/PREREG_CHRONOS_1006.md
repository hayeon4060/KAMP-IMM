# 시계열 파운데이션 모델(Chronos) 예측 오차 점수 — 결과 보기 전 고정 (2026-10-06 22:30 KST)
지위: 탐색적. 제출 모델·원장은 어떤 결과든 바꾸지 않는다. 실행: src/explore/exp_chronos.py (로컬, 모델 가중치 내려받기 필요).
방법: 같은 Run 안 직전 최대 64쇼트(최소 10)의 원값 21개(맥락 중앙값을 뺌)로 다음 쇼트 1개 예측. 기본 amazon/chronos-2(다변량), 보조 amazon/chronos-bolt-small(변수별).
점수: 변수별 오차 = (실제 − 예측 중앙값) / max(예측 90%−10% 폭, 기록 눈금), rms(주)·max(보조). 경보 = 정상 추정 기준 무작위 3,000쇼트 점수 99.9백분위.
비교: 원장 쇼트(정답 = 어느 쪽이든 불량)에서 제출 모델·기준선(강건 z)·지도 RF와 AP, 상위 5% 불량, 운용점 경보·잡은 불량, 새로 잡은/놓친 불량(쇼트 단위).
예측: CN7 10/16 사건·10/27 재가동은 일부 잡음(큰 이탈), 제출 모델보다 경보가 많음. 한쪽 가스·11/03·RG3는 무작위(확신 75%) — 직전 맥락 대비 예측 오차는 제출 모델의 '직전 대비 편차'와 같은 정보를 본다.
