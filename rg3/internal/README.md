# RG3 내부 의존 코드

사용자는 상위 01/02 노트북만 실행합니다. 이 폴더는 원본 함수의 동작을 유지하면서 하연 실험 브랜치 의존성을 없애기 위해 포함했습니다.

- notebooks/09, 10, 158 및 preprocessing/: 원단위 연결·샷·Run·과거 센서 이력 생성.
- notebooks/22, 42, 54, 154, 193: 가스 12개 모델 함수와 구간 제외 검증.
- notebooks/133, 139, 141, 143, 145: 미성형 기준 후보와 피처·학습 함수.
- notebooks/204, 205: 실제 15개 기본 분류기 재학습·저장.
- notebooks/207~211: 비라벨 이력 재구성, 온도 상태별 D 보완·분기, 저장/재현 확인.
- notebooks/212: 기존 학습 함수 정의를 읽기 위한 보존 소스. 별도로 실행하지 않습니다.
- data/taein/*.py: 기존 팀원 코드의 원본 라이브러리 복사본. 원본 데이터가 아닙니다.

생성되는 reports/, models/, raw_input/, original_split/, taein/base·linked·outputs는 Git에서 제외됩니다. 역사 예측 CSV는 동봉하지 않으며, 현재 실행이 필요한 중간 예측을 직접 만듭니다. 과거 비교·대안 분석이 학습 검증의 일부로 남아 있어 01의 학습 모델 수는 최종 저장 분류기 28개보다 많습니다. 02는 재학습하지 않습니다.
