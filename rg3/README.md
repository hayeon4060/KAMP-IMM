# RG3 — 하연 가스12개 + 최고 미성형

두 노트북만 순서대로 실행한다.

1. `01_preprocess_train.ipynb`: 원본/KAMP 전처리 → 가스12개 전체 구간제외 재현 → 최고미성형143 개발평가 재현 → 두 저장모델 생성 → 가공데이터 생성.
2. `02_predict.ipynb`: 저장모델만 로드해서 `INPUT_CSV` 예측. 재학습 없이 가스/미성형 둘 다 실행한다. 둘 다 양성이면 `가스+미성형 후보`로 표시한다.

환경: Python3.14, 먼저 `python -m venv .venv-rg3`, `.venv-rg3\Scripts\Activate.ps1`, 다음 `python -X utf8 -m pip install -r rg3/requirements.txt`. 노트북 커널도 해당 환경을 사용한다.

저장 모델은 `models/gas12.joblib`, `models/shortshot_best.joblib`. joblib/pickle은 임의 파일을 로드하면 코드가 실행될 수 있으므로 신뢰된 이 저장소 생성물만 사용한다. 가스 모델은 SHA256/라이브러리 버전 검사 포함.

가스 구성: RF2 + 패턴RF4 + 열RF/ET/LR3 + 압력RF/ET/LR3 =12분류기. 정상관계Ridge4개 전처리는별도다. 미성형은기존A/B/C/D네가지관측가설을결합한143후보이며가스12개와같은숫자의모델은아니다.

최고미성형의저장분류기는38개(A9+B7+C21+D1)다. 가스12개를합친RG3전체패키지는50분류기이며,이번축소는가스쪽만진행했다. 전체패키지가12분류기라는뜻은아니다.

새12개가스+최고미성형을둘다실행해OR로묶은구간제외개발평가는591샷/불량25,TP14/FP18/FN11/TN548/F1.4912다. 평가구간을빼고학습한가스모델로미성형8샷도추가점수화해집계했으며,기존50개가스조합의결과를복사하지않았다.

공식 개발평가: 가스17/정상566,TP8/FP7/FN9/TN559/F1.500. 미성형8/정상566,TP6/FP11/FN2/TN555/F1.480. 가스는583샷전부기존후보와동일함을전체새학습으로확인했다. 이는이미결과를보면서개발한구간검증이며새독립최종검증이아니다. Fullfit 모델의학습행예측으로F1을계산하지않는다.

기본 `INPUT_CSV`는 `dataset/processed/rg3/rg3_input_features.csv`. 원단위24센서/설비/제품/시각/가스인과이력및미성형std/physical/shock/joint/context컬럼을포함한다. 원본KAMP표준화24컬럼만바로넣는것은지원하지않는다. 기존미성형의희소라벨샷기반이력과새연속센서이력은분포가다를수있으므로가공스키마에맞춘새입력은별도분포점검필요.

가스 비라벨 결과:734/28710=2.56%,작동추정731/15797=4.63%. 경보후보이며실제불량확정/정확도가아니다. 저장모델은전체라벨학습용,OOF예측은보고서용으로구분한다. 기존50개가스의cascade평가숫자를새12개결합성능으로재사용하지않는다.
