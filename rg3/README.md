# RG3 — 확정 구성: 가스12개 + 보완 미성형16개

## 실행 순서

1. `01_preprocess_train.ipynb`: 원본 복원/전처리 → 가스12개 재현/학습 → 미성형15개 기본모델 학습 → 상태별D1 보완 → 저장모델/가공CSV 생성.
2. `02_predict.ipynb`: 저장모델을 읽어 가스와 보완 미성형을 모두 예측한다. **재학습하지 않는다.** 기본입력은 같은6590개의비라벨샷을전처리한 `dataset/processed/rg3/rg3_unlabeled_input_features.csv`다.

환경은Python3.14다. 먼저가상환경생성/활성화후설치한다.

```powershell
python -m venv .venv-rg3
.\.venv-rg3\Scripts\Activate.ps1
python -X utf8 -m pip install -r rg3/requirements.txt
```

노트북 커널도 이 환경으로 선택한다. 먼저 데이터 준비 안내에 따라 파일을 배치하고 01을 실행한다. 이미 동일한 스키마의 가공 피처 CSV가 있는 경우에는 동봉된 저장 모델로 02부터 실행할 수 있다. 01은 내부 전처리/구간검증을 다시 돌리므로 02보다 오래 걸린다. 필요한 내부 코드는 `internal/`에 포함되어 있으며 `hayeon/` 폴더를 필요로 하지 않는다. 사용자 실행 진입점은 두 노트북이다.

## 모델 및 입력

- `models/gas12.joblib` / `.json`: RF2+패턴RF4+열RF/ET/LR3+압력RF/ET/LR3.
- `models/shortshot_routed_D.joblib` / `.json`: A9+B2+C3+기존D1+상태별새D1=16분류기.
- 합계28분류기이며정상관계Ridge4회귀/최근접기준선은별도전처리다.
- 이전 38개 미성형과 중간 실험은 이 최종 배포 브랜치에 포함하지 않는다.

미성형은기존정상온도9개변수의지원범위안에서는기존D를쓰고,밖에서는과거비라벨4081샷의강건중앙값/MAD기준으로정규화한새D를쓴다. 비라벨에정상라벨을붙인것이아니며분류기학습은실제라벨만사용했다. 참조는첫공식라벨1시간전인2020-10-20 23:16:26이전으로제한하고참조조건은각학습폴드의정상값으로만정한다. 새D의경보선은학습내부정상99.5%로고정했다.

02의 `INPUT_CSV`를수정해다른전처리된샷CSV를사용한다. 입력은원단위공정센서/설비/제품/시각/가스과거이력및미성형std/physical/shock/joint/context피처가필요하다. 상태분기에는배럴1~6/호퍼/금형3~4원값도필요하다. KAMP표준화24컬럼을바로넣으면안된다. 입력생성시동일설비의앞선센서이력이필요하며시각/샷중복과센서충돌을확인해야한다. 기본라벨예제는 `rg3_input_features.csv`; 이는전체학습후모델의샘플추론이지성능평가가아니다.

SHA256과라이브러리버전을확인한다. joblib/pickle은코드실행가능형식이므로이저장소에서직접생성한신뢰파일만로드한다. 예측CSV의가스/미성형/둘다경보는후보표시이지불량확정이아니다. 경보없음도정상확정은아니다.

## 반드시 남겨야 하는 한계

이미본자료로개발한후보이며새독립최종시험이아니다. 미성형라벨8개는모두기존온도지원상태안에있고,새상태로분기된라벨90샷은모두정상이다. 따라서새D가다른상태에서진짜미성형을검출하는지는미검증이다. 과거비라벨의다수가정상적공정이라는강건기준선가정이있어불량을기준선으로흡수할위험이있다. 비라벨경보율감소를실제오탐감소로확정하지않는다. 역사비라벨결과는학습후소급적용이며엄격한온라인미래검증이아니다.
