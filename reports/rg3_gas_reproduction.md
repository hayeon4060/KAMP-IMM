# RG3 가스 분석 재실행 안내

## 이 커밋의 범위

`notebooks/22_rg3_nested_signal_ensemble.ipynb`와 요약 보고서, 평가 지표, 샷별 예측, 판정 기준, 구간별 평가 내역을 보관한다. 기존 단독 모델과의 재현 일치 검증용 예측 결과도 포함한다. 원본 데이터와 센서값이 포함된 입력 CSV는 포함하지 않는다.

## 필요한 로컬 데이터

별도로 `reports/tables/original_labeled_shot_features.csv`를 준비해야 한다. 이 파일에는 기존 분석 과정에서 원본 센서값과 이전 샷의 통계량을 결합한 데이터가 들어 있다. 노트북은 RG3 정상 566개와 가스 17개만 선택하며 미성형은 제외한다. 입력 CSV가 없으면 이 커밋만으로 모델을 재실행할 수 없다. 데이터 공유 권한을 확인한 뒤 별도 전달한다.

## 실행 방법

기존 `.venv`를 활성화한 후 필요한 패키지를 설치한다. 새 환경을 사용하는 경우에도 환경 생성 및 활성화를 먼저 한다. 실행 당시 버전은 numpy 2.5.3, pandas 3.0.6, scikit-learn 1.9.1이다. 노트북 커널을 해당 환경으로 선택하고, 프로젝트 루트 또는 notebooks 디렉토리에서 전체 셀을 실행한다. 현재 노트북은 hayeon 브랜치를 확인한다.

실행하면 결과 CSV와 `rg3_nested_ensemble_comparison.md`가 갱신된다. 저장된 보고서의 수동 핵심 해설은 재실행 시 덮어써질 수 있으므로 기존 커밋의 보고서를 함께 참고한다.

## 평가 해석

RH 기준 구간 제외 검증에서 최대 점수 결합과 학습 정상 99% 판정 기준은 AP 0.1686, TP 4 / FP 6 / FN 13 / TN 560이었다. 과거 구간만 학습한 평가는 AP 0.0812, TP 2 / FP 4 / FN 11 / TN 423이다. 동일 데이터로 반복 탐색한 결과이며 독립적인 최종 성능으로 간주하지 않는다. 정상의 99% 분위수로 기준을 정해도 새로운 구간의 오탐률 1%를 보장하지 않는다.
