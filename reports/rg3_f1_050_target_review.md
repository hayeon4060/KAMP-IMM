# RG3 가스 F1 0.5 목표 — 58~61번 실험
> 최신 추가검증: 정답을 보기 전에 모델·규칙을 고정해 별도 37개(가스2·정상35)를 예측한 결과, TP0·FP12·FN2·TN23·F1=0이었다. 아래0.516은 탐색 기록이며 일반화 개선은 확인되지 않았다. 상세: reports/rg3_independent37_blind_validation_review.md. 이번37개는이미개봉했으므로다시튜닝해독립검증이라고부르지않는다.

## 결론
보유 RG3 RH 가스17개·정상566개의 **전체 관측구간 제외 평가에서 F1=0.516(8TP/6FP)**인 탐색 후보를 찾았다. 원래57번 다수결6TP/6FP/F1=0.414보다 가스2개 추가, 정상오탐 개수와 샷은 그대로다.
그러나 테스트 사례를 보며 가설을 만들고 조합을 선택했다. **독립적으로 검증된 F1 0.5, 대회 공식 성적, 실제 원인 확정이 아니다.** 과거→이후 평가에서는3TP/4FP/F1=0.300으로 원래와 같아 일반화 개선을 주장하지 않는다.

## 새로 찾은 샷
57번6개 후보 대비 추가:
- 2020-10-22 01:26:54: 앞선54번 온도 확인 분기. 전체 온도 전문가의 정상참조 수 변화에 민감했던 사례이며,57번 다수결에서는 보류했던 가스다.
- 2020-10-22 01:57:47: 이번 압력 전환 확인 분기. 기존8개가 아니라 원래6개에 위2개를 더해8개다.

둘은 같은 가장 이른 가스 관측구간에 있다. 그 이전 라벨41개에는 가스0개여서 두 클래스 학습이 가능한 이후 구간만 평가한 과거→이후 방식에서 이 두 샷은 테스트 대상이 아니다. 전체 구간 제외 방식에서는 뒤의 가스 구간을 학습해 이른 샷을 예측한다. 두 사례를 미래 검증에 성공한 샷으로 세거나, 반대로 과거 평가에서 탐지실패한 샷으로 세면 안 된다.

## 모델과 파생피처
기존 모델을 유지하고, 새 분기가 기존 불량 판정을 삭제하지 않는 OR 방식이다.

### 온도 분기: 이전54번 그대로
배럴–금형 온도차, 금형3/4 차이·변화·자기편차, 배럴5변화−금형평균변화, 최고압/충진시간6개를 비슷한 조건의 학습 정상30개와 비교한 편차로 만든다.
RF/ExtraTrees각3seed 평균 + 로지스틱3개C 평균을 결합한다. 전문가 점수는 내부 정상97.5% 경계, 열변화 차이 편차는 내부 정상 하위5% 확인조건이다. 이54번은 참조20/40개에서 결과가 달랐으므로 안정적인 확정 모델이 아니다.

### 새 압력 분기: 58~60번
6개 피처:
1. 현재 최고압 변화−현재 전환압 변화
2. 현재 최대사출속도 변화
3. 현재 충진시간 변화
4. 최고압의 과거10샷 편차−전환압의 과거10샷 편차
5. 현재 쿠션 변화
6. 배럴5 변화−금형 평균 변화

현재−직전 센서 차이를 쓰며 미래 샷은 쓰지 않는다. 비슷한 속도·충진시간·배럴5·금형3 조건의 학습 정상30개와 비교한6개 편차를 입력한다. 실제 보압·압력적분·에너지로 해석하지 않는다.
모델은 RF100/depth5/leaf3, ExtraTrees100/depth5/leaf3, LogisticRegression C=0.1/1/10 평균. RF·ExtraTrees의3seed 점수평균과 선형점수평균을 다시 평균한다. 전문가 점수가 내부 정상99% 경계를 넘을 때도 다음 방향을 함께 확인한다.
- 최고사출압이 직전보다 감소
- 최대사출속도가 직전보다 증가
- 전환압이 최고사출압보다 더 크게 감소

부동소수점 잡음을 변화로 세지 않도록 압력·속도 차이는 소수2자리로 반올림한다. 사출속도가 올라가는데 압력 응답이 낮아지는 관계를 시험한 것이며, 실제 압력전달실패·공기갇힘·배기불량을 증명한 것은 아니다.

01:57:47에서는 최고압−0.20, 전환압−0.30, 최대속도+0.10, 쿠션+0.010이 관측됐다. 58번 점수0.65584는 내부 정상 경계0.65185보다 조금 높았다. 이 샷을 본 뒤 방향 확인 가설을 만든 것이므로 **아이디어 선정의 테스트 영향**을 숨기지 않는다.

## 검증 범위와 한계
61번으로 다음을 확인했다.
- 실제 예측으로2×2/F1 재집계; 전체583개·과거440개, 각 시각의 예측중복 없음.
- 원본 RH 라벨과 센서용 샷라벨 일치. CN7/LH/미성형8개는 이 평가에 포함되지 않음.
- 기존 탐지 유지, 고정2-of-3 결합 규칙 일치.
- 원본 전체 센서 이력에서 최고압·전환압·최대속도·쿠션의 직전 변화 재계산 일치.
- 모든 외부 학습/평가구간·시각 분리; 과거 평가의 참조구간은 실제로 이전 시각만 포함.
- 추가2개의 과거평가 대상 여부 확인. 전체 평가의 정상오탐6개는 이전57번과 동일한 샷.

구간을 모델 학습에서 뺐다는 것과, 연구자가 평가 결과를 보고 피처를 만든 것이 독립적이라는 것은 다르다. 이 실험은 후자의 독립성을 갖추지 못했다. 따라서 ‘평가자료를 모델에 직접 학습하지 않았다’고만 말하며 검증오염이 전혀 없다고 주장하지 않는다. 공식 테스트나 새로운 생산구간에서 규칙을 고정해 재검증해야 한다.
5개 구간은 라벨 시각의30분 공백 기준 관측구간이며 실제 설비Run 확정값이 아니다. 이전 센서 이력·Timestamp가 공식 테스트에 제공되는지도 확인이 필요하다. 실제 원인 판정에는 세부가스불량 사진·건조/수분·보압/캐비티압·배기보전 기록이 필요하다.

## 판단
숫자 목표 F1≥0.5를 만족한 **탐색 후보**를 보관한다. 실전·독립검증 성능의0.5 달성이나 원인 확정으로 발표하지 않는다. 더 보수적인7/6후보도 별도로 남긴다. 독립 자료 없이 같은평가를 계속 최적화한 최고기록을 믿을만한 성능으로 바꾸는 것은 불가능하다.
