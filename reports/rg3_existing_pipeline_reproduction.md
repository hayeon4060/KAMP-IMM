# 이미 연결된 RG3 코드의 실행 패키지

이번 변경은 기존 코드133/139/141/143/145/152/153을 다른 컴퓨터에서 실행하도록 누락 소스·공통 로더·입력을 보충한 것이다. 모델·피처·임계값·조합을 새로 바꾸지 않았다. 작업 폴더에 있던133/139/141/145의 절대경로만 저장소 상대경로로 수정했다.

## 실행 방법

1. GitHub의 **hayeon 브랜치**를 내려받는다. 저장소 루트에서 가상환경을 만들고 활성화한 다음 requirements.txt를 설치한다.
2. 저장소 루트를 작업 디렉토리로 설정하고 해당 환경의 Python 커널로 `notebooks/157_rg3_existing_connected_pipeline_runner.ipynb`를 실행한다.
3. 실행 순서는 기존133→139→141→143→152→153. 가스 모델의 앞 단계22/47/54/58~60 정의와 이미 저장된 내부학습 경계를152번이 재사용한다. 필요한 파일은 저장소에 동봉한다.
4. 미성형 비라벨 적용까지 보려면157번의 RUN_UNLABELED_APPLICATION을 True로 한다. 이 경우 기존145번이 추가 실행된다. 비라벨은 정답이 없어 F1을 계산하지 않으며, 희소 라벨 이력과 밀집 비라벨 이력의 차이가 있는 탐색 적용이다.

133/139/141 학습 로더가 쓰는 기존 `data/taein` 코드(semi_normal.py, semi_sup.py, final_model.py)와 base/linked/outputs 입력을 포함했다. 이 Python 파일들은 기존 팀 코드의 의존성이며 이번에 새로 만든 모델이 아니다. CN7 원본 분리 파일은145번에서 설비 제품 전환·이력 경계를 확인하기 위해 필요하며, CN7 모델을 학습하는 뜻이 아니다.

## 기존 결과 재현 목표

Git에 올릴 파일만 담은 임시 복사본에서133→139→141→143→152→153 전체와145번 비라벨 적용을 실제 실행해 통과했다. 아래 혼동행렬도 일치했다. 검증 기록은 `tables/rg3_connected_pipeline_clean_checkout_check.json`에 있다.

| 평가 | TP | FP | FN | TN | F1 |
|---|---:|---:|---:|---:|---:|
|가스만583 Shot|8|6|9|560|0.5161|
|미성형만574 Shot|6|11|2|555|0.4800|
|가스→최고 미성형, 전체591 Shot|14|17|11|549|0.5000|

이는 기존 구간제외 개발 예측을 재현하는 목표이지 독립 테스트 성적이 아니다.153번 연결은 예측된 가스 음성에 대해서만 미성형 판정을 확인하며 실제 정답으로 분기하지 않는다.143번은 A|B|C|D 결합으로,133번 A/B,139번 C,141번 D를 사용한다.

## 새 데이터 추론과의 구분

155번+동봉 가스 가중치는 학습 없는 **가스 새 입력 추론**이다.157번은 **이미 연결된 원본 학습·평가 흐름의 재실행**이다.145번은 기존 미성형의 비라벨 탐색 적용이다. 이 서로 다른 목적을 동일한 완성된 단일 가스/미성형 운영 모델로 혼동하지 않는다. 최고 미성형의 별도 저장 가중치 기반 추론 API까지 완성했다고 주장하지 않는다.

기존 입력 파일은 사용자가 제공한 KAMP 관련 원본/연결 데이터로, 별도의 자유 데이터 라이선스를 새로 부여하지 않는다. 전체 대용량 original 또는 환경 폴더는 업로드하지 않는다.
