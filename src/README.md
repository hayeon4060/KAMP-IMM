# Analysis rules

이번 분석은 실행 코드를 별도 Python 파일로 분리하지 않고 노트북에 유지한다.

- `Unnamed: 0`은 원본 행 식별자이므로 분석 변수에서 제외한다.
- `PassOrFail`은 가이드북 정의에 따라 `0=양품`, `1=불량`로 해석한다.
- 상수열은 상관계수가 정의되지 않으므로 제품별 계산에서 제외한다.
- 변수 간 구조는 표본 수가 큰 라벨+비라벨 데이터를 제품별로 합쳐 계산한다.
- 불량 연관성은 라벨 데이터만 사용한다.
- Pearson 결과와 함께 순위 기반 Spearman 결과를 제공해 비선형 단조 관계와 이상치 민감도를 함께 확인한다.
- 상관관계는 인과관계를 의미하지 않는다.

## 불량 유형 분석 자료

- 대회용 2차 가공 CN7/RG3 파일에는 `Reason`이 없고 `PassOrFail`만 있다.
- `data/original/moldset_labeled.csv`에는 `가스`, `미성형`, `초기허용불량` 라벨이 있다.
- 원본은 대회 제공본이 아닌 참고 자료이므로 분석 해석에는 사용할 수 있지만, 모델 학습이나 제출물 사용 가능 여부는 대회 규정을 확인해야 한다.
